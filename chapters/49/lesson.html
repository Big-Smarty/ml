What survives when a sequence keeps only one number?

Start with state h=1 and apply transitions (a,b)=(0.5,1), (0.2,−0.5), (0.8,0.1). Updating

h←ah+b

gives 1.5, −0.2, then −0.06. A sequence model can carry a compact state instead of retaining every previous key and value.

Here a is a retention multiplier and b is this step’s input contribution; neither is the reusable bias of a trained neuron. The output equals the new scalar state. More general state-space models use vectors, structured transition matrices, and separate readout parameters. Our fixed formulas illustrate state dynamics; this is not a trained S4 or Mamba model.

Retrieve chapter 23’s recurrence: the next state depends on the previous state. If |a|<1 repeatedly, old information tends to decay. Values above one can amplify it and negative values can alternate its sign. Compressing a prefix into one scalar also loses distinctions that a later query might need. Constant inference state is a resource property, not proof of equal sequence-model quality.

Can the current input decide what to retain?

The supplied selective transition uses a=sigmoid⁡(1.2−0.8|x|) and b=(0.7+0.2x)x. For x=0.5, a≈0.6900 and b=0.4. Starting from h=0.3 gives 0.6900×0.3+0.4≈0.6070. For x=2, a≈0.4013: this chosen rule retains less old state when the input magnitude is large.

Selective means the coefficients depend on input content. Mamba learns a much richer input-dependent system. These numerical constants are course choices with no learning procedure. Validation rejects empty or nonfinite input and a finite value whose input contribution overflows. A sigmoid bounded between 0 and 1 does not make every other part of a calculation safe from overflow.

Represent a transition by its two numbers. Applying earlier T1⁡(h)=a1h+b1 and then later T2 gives a2(a1h+b1)+b2. Collecting terms gives (a2a1,a2b1+b2). For our first two transitions that is (0.1,−0.3), which maps h=1 directly to −0.2. Reversing the order gives constant term 0.75 instead: composition is not commutative.

It is associative: changing the parentheses preserves the order of function application. That is what permits a scan. Input-dependent coefficients do not break the argument once their per-position values are known.

impl Transition {
    /// Apply `earlier`, then `self`.
    fn after(self, earlier: Self) -> Self {
        Self {
            a: self.a * earlier.a,
            b: self.a * earlier.b + self.b,
        }
    }

    fn apply(self, state: f64) -> f64 {
        self.a * state + self.b
    }
}

Which summary can answer a new query?

Ordinary softmax attention scores the current query against each earlier key. A different feature kernel can collect key/value information before the query arrives. This lab uses φ⁡(u)=max⁡(u,0)+1 componentwise. Query and key arrays have shape [positions,2], values are scalar [positions], and outputs are scalar [positions].

Maintain two two-vectors: value summary S and normalizer z, initially 0. At position t, add S←S+φ⁡(kt)vt and z←z+φ⁡(kt). Then return

φ⁡(qt)·Sφ⁡(qt)·z+10−12.

The ε is a small denominator safeguard, not learned noise. The feature map makes every coordinate at least 1, so valid nonempty prefixes have positive denominators.

With first q=[0,1], k=[1,−1], and value 2, their features are [1,2] and [2,1]. S becomes [4,2], z becomes [2,1], and the output is (4+4)(2+2)=2, up to ε. Add current key/value before reading to include the current position; reading first would define exclusive attention.

At the second position, the output need not be the ordinary mean of two values. The current query weights their feature similarities. The check’s values [2,−1,0.5] give uniform baseline [2,0.5,0.5], while the direct feature-kernel oracle gives approximately [2,0.60698027,0.53705693]. The difference tells you what information the baseline discarded.

What did constant state leave out of the claim?

The recurrent and direct implementations must agree for the same feature kernel. The direct oracle explicitly sums query-feature dot key-feature times values for each permitted prefix. Distributing the query dot product over the key/value sums yields the recurrence. No step in this algebra turns ReLU-plus-one features into exp⁡(query·key); this is not exact softmax attention.

For feature width dφ and value width dv, S has shape [dφ,dv] and receives an outer product each token. z has dφ numbers. The recurrent state therefore uses dφdv+dφ numbers, independent of sequence length, and each token costs O⁡(dφdv) arithmetic. A vector-valued generalization must divide every output component by the same query-dependent scalar.

Streaming inference can consume each output immediately and retain only the summaries. This comparison program stores every output to check prefix agreement, so its result vectors still use O⁡(N) memory. Training may need saved states or recomputation for backward. Always name the phase and arrays included in a memory claim.

The supplied timing compares a 4,096-position recurrence with only a 256-position direct oracle and uses single observations. Those observations are diagnostics, not an honest speedup ratio. Use the release benchmark discipline from chapter 25 for a timing study with identical lengths and repeated trials. The primary lesson here is numerical equivalence and what compression loses.
