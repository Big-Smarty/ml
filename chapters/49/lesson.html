Attention carries information between sequence positions through pairwise interactions and a growing key-value cache. Another family keeps a compact recurrent state. The apparent serial loop can sometimes be reorganized as an associative scan for training, and a related feature-map trick turns one kind of attention into recurrent summaries. We will implement and compare all three views without claiming they are the same model.

The concrete goal

You will evaluate an input-dependent scalar state-space recurrence, derive an associative affine composition, reproduce every recurrent state with a scan schedule, and check a causal linear-attention recurrence against a direct prefix oracle.

1. Carry a state instead of every past token

A state-space model summarizes a sequence in a hidden state h. In a scalar discrete system, one step can be written

ht = atht−1 + bt    yt = ctht

The transition coefficient a controls retention of prior state. The input contribution b writes current information. The readout c maps state to output; our fixture uses c=1 so output equals state. A vector system replaces scalars with matrices or structured operators, but the scalar case exposes the exact sequence dependency.

This is a recurrence: ht needs ht−1. During one-token autoregressive inference, that is useful. Keep the latest state, process the new token, and discard old inputs if no other component needs them. State memory stays constant with sequence length.

Three recurrent steps

Start h₀=1. Let transitions (a,b) be (0.5,1), (0.2,−0.5), and (0.8,0.1). Then h₁=0.5×1+1=1.5. Next h₂=0.2×1.5−0.5=−0.2. Finally h₃=0.8×(−0.2)+0.1=−0.06. Each output contains a transformed contribution from earlier inputs.

When |a| is consistently below one, old state tends to decay. Values above one can amplify it; negative values can alternate signs. Real state-space parameterizations constrain or discretize dynamics for stability and expressiveness. Our coefficients remain between zero and one through sigmoid, which makes this fixture tame but does not establish general training stability.

2. Let input control what state retains

Fixed coefficients treat every position by the same dynamics. Selective state makes some coefficients depend on the current input. Mamba uses input-dependent state-space parameters within a much larger trained architecture. Our course fixture chooses transparent scalar formulas:

at = sigmoid(1.2 − 0.8|xt|)    bt = (0.7 + 0.2xt)xt

A larger input magnitude lowers a in this formula, so the state retains less of its previous value. The b formula writes a signed nonlinear contribution. These constants were chosen for bounded, visible behavior. They are not learned and are not a Mamba parameterization.

Build one selective transition

For x=0.5, a=sigmoid(1.2−0.4)=sigmoid(0.8)≈0.6900. The input contribution is (0.7+0.1)×0.5=0.4. If previous state is 0.3, the new state is 0.6900×0.3+0.4≈0.6070. For x=2, a=sigmoid(−0.4)≈0.4013, so this chosen rule retains less old state.

The project first transforms every input into its per-token pair (at,bt). Once those maps are known, the recurrence has a useful algebraic structure. Input dependence does not prevent scanning; it means the transition list must be computed from inputs before composition.

The input boundary rejects empty sequences, nonfinite values, and finite inputs whose squared input contribution overflows. Stable sigmoid uses different forms for positive and negative arguments to avoid unnecessary overflow. Although finite inputs and bounded a keep this fixture controlled, longer or higher-dimensional systems need explicit numerical monitoring.

3. Turn serial updates into associative maps

Represent one step as affine map T=(a,b), acting on h as T(h)=ah+b. Suppose T₁ is earlier and T₂ later. Applying them in time order gives

T₂(T₁(h)) = a₂(a₁h+b₁)+b₂ = (a₂a₁)h + (a₂b₁+b₂)

Define composition “later after earlier” as

(a₂,b₂) • (a₁,b₁) = (a₂a₁, a₂b₁+b₂)

This operation is associative: T₃•(T₂•T₁)=(T₃•T₂)•T₁. It is not commutative; reversing maps usually changes the b term. Associativity means parentheses can change without changing order. That is exactly what a prefix scan needs.

Compose the first two steps

Using (0.5,1) then (0.2,−0.5), the composition is (0.2×0.5, 0.2×1−0.5)=(0.1,−0.3). Applied directly to h₀=1, it gives 0.1−0.3=−0.2, matching the two-step recurrence. Reversing the order gives b=0.5×(−0.5)+1=0.75, clearly a different sequence.

An associative scan returns every prefix composition, not only the final one. The reference uses offsets 1,2,4,… . At each round it clones the previous prefixes, then combines position i with the prefix i−offset. After logarithmically many rounds, each position holds the map from sequence start through itself.

let mut offset = 1;
while offset < prefixes.len() {
    let previous = prefixes.clone();
    for i in offset..prefixes.len() {
        prefixes[i] = previous[i].after(previous[i - offset]);
    }
    offset *= 2;
}

This is a Hillis–Steele style teaching schedule. It has O(log N) dependency depth but performs O(N log N) scalar work, clones each round, and executes sequentially in this Rust program. It will normally be slower than the direct O(N) recurrence on one CPU thread. The point is to prove reorganizable dependencies. A production parallel scan needs actual threads or accelerator dispatch and usually a work-efficient schedule.

4. Recur through an attention-like summary

Ordinary softmax attention computes similarities between a query and many keys, then normalizes weighted values. For every prefix, a direct implementation revisits all earlier positions. Some kernels replace exponential pair scoring with a feature map φ whose dot product can be regrouped. This produces linear attention.

For two-dimensional queries and keys and scalar values, maintain a two-vector value summary S and normalization summary z:

St = St−1 + φ(kt)vt    zt = zt−1 + φ(kt)
ot = [φ(qt)·St] / [φ(qt)·zt + ε]

The reference uses φ(u)=ReLU(u)+1 componentwise. Every feature is at least one, keeping the denominator positive for nonempty finite prefixes. This feature choice defines a different attention kernel from exact softmax. The recurrent rewrite is exact for this chosen feature kernel; it is not an exact rewrite of softmax attention.

One causal prefix

Let q=[0,1], k=[1,−1], and v=2 at the first position. Features are φ(q)=[1,2] and φ(k)=[2,1]. Then S=[4,2], z=[2,1]. The numerator is 1×4+2×2=8; denominator is 1×2+2×1=4. Output is 2, the only available value. The ε affects only the final tiny digits.

The update adds the current key and value before reading the current query. Therefore position t sees indices j≤t: an inclusive causal prefix. Adding after the query would accidentally exclude the current token. Adding all keys before all queries would leak future positions.

To generalize the storage, let the key/query feature map have dimension dφ and each value have dv components. S is then a [dφ,dv] matrix. Updating it requires the outer product φ(k)vᵀ, while z remains a dφ-vector. Reading a query multiplies its feature row by S and divides every output component by the same scalar normalizer. The state therefore occupies dφdv+dφ numbers, independent of sequence length, but each token costs O(dφdv) work. “Linear in sequence length” does not mean independent of feature width.

This fixed state creates a modeling tradeoff. Softmax attention can compare the current query with each stored key separately. The linear recurrence has already compressed all keys and values into sums; it cannot recover distinctions that those sums discard. Likewise our one-dimensional SSM funnels the entire prefix through one scalar. Neither faster asymptotic scaling nor a passing recurrence test establishes equal retrieval ability, long-range recall, or language-model quality. Those questions require trained models and tasks that demand the missing distinctions.

Training introduces another distinction from streaming inference. The reference returns a vector of every output so it can compare prefixes, using O(N) output storage. A streaming consumer that immediately uses each output can retain only the current state or summaries. Backpropagation may need saved intermediate states or recomputation, however, so constant inference-state memory is not automatically constant training memory. Specify which phase and which arrays a memory claim counts.

The direct oracle loops over j=0..t for every t and calculates the same feature similarities. It costs O(N²) work but has simple indexing. The recurrent version costs O(Nd) for feature dimension d and keeps fixed-size summaries. Their tolerance agreement checks the recurrence and causal boundary. It does not compare either result with softmax attention.

cargo test --manifest-path projects/ch49/Cargo.toml

The complete reference implementation generates 4,096 sinusoidal inputs. It computes fixed selective transitions, evaluates both recurrence and scan, and rejects any parity mismatch. It runs recurrent linear attention over the whole sequence and checks the first 256 outputs against the direct prefix oracle.

The executable prints current elapsed times. Treat them as illustrative observations: they are single-process CPU timings, the sequential scan intentionally does extra work, and the direct oracle uses only 256 tokens while the recurrence uses 4,096. The program reports no speedup ratio. It also prints that its fixed selective coefficients are not a trained Mamba layer.

The tests cover scan parity from a nonzero initial state, explicit associativity, recurrent-versus-direct linear attention, empty sequences, mismatched lengths, and nonfinite inputs. Tolerances combine an absolute floor and a relative term because regrouped floating-point operations need not be bitwise equal.

Hint 1 · Preserve time order

Hint 2 · Collect h and constant terms

The h coefficient is later.a×earlier.a. The constant is later.a×earlier.b+later.b.

Worked solution
Transition {
    a: later.a * earlier.a,
    b: later.a * earlier.b + later.b,
}

The order is visible in the b formula even though scalar multiplication makes the a product look symmetric.

Hint 1 · Use a nonzero initial state

Zero can hide a wrong accumulated a coefficient. Start at 0.4.

Hint 2 · Test noncommutativity

Choose different b values and confirm reversing two transitions changes the result.

Reference checkpoint

Only after the O(N²) prefix oracle agrees should you compare the offset-doubling schedule. At each round, read all operands from the previous round.

Debugging · The scan matches only when initial state is zero

A learner composes b correctly but sets every combined a to zero. All zero-initial tests pass for a fixture whose b happens to dominate.

Answer

The composed map must preserve how the original initial state flows through every transition. Test with a nonzero initial state and compare both composed fields, not only one final output. The correct a is the ordered product of transition coefficients.

Independent variation · Exclusive causal output

Change linear attention so output t may use only j<t, excluding the current key and value. Decide the first output and change the operation order.

Worked answer

Read the query from the old summaries before adding the current key-value pair. At t=0 the summaries are empty, so define and document the result—zero is a reasonable convention with the ε denominator. Then add the current pair for later positions. A direct oracle must loop over 0..t rather than 0..=t.
