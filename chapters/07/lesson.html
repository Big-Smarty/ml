A single neuron draws one straight decision boundary. XOR asks for the opposite corners of a square to share a label, so no straight line can separate its two classes. This chapter adds one hidden layer, bends the boundary, and derives every gradient used to train it.

Milestone

You will train a 2–2–1 multilayer perceptron on all four XOR rows. The program contains no ML crate and no invented gradients: its backward pass follows the chain rule, and numerical differences independently check both layers.

1. See what one neuron cannot represent

XOR, or “exclusive or,” returns one when exactly one input is one. Its four examples are (0,0)→0, (0,1)→1, (1,0)→1, and (1,1)→0. Plot the inputs as corners of a square. A linear classifier predicts from z = w₀x₀ + w₁x₁ + b and places one class on each side of the line z = 0. Whichever line you choose, it cannot isolate two diagonal corners from the other two.

This is a limitation of the model family, not the optimizer. More iterations cannot make a straight boundary bend. Regularization cannot add missing expressive power. The smallest useful repair is a hidden layer: intermediate neurons whose outputs become features for the final neuron.

Our network has two inputs, two hidden neurons, and one output. Dense connections give it four input-to-hidden weights, two hidden biases, two hidden-to-output weights, and one output bias. The hidden neurons apply a sigmoid nonlinearity σ(z)=1/(1+e−z). Without this nonlinear function, composing two dense layers would collapse into another straight line.

A forward pass with numbers

Take input x=(1,0). For the first hidden neuron use weights (0.7,−0.4) and bias 0.1. Its pre-activation is z₀=0.7×1−0.4×0+0.1=0.8, so h₀=σ(0.8)≈0.6900. The second has weights (−0.2,0.9) and bias −0.3: z₁=−0.5 and h₁≈0.3775. With output weights (0.8,−0.6) and bias 0.2, the output logit is 0.8×0.6900−0.6×0.3775+0.2≈0.5255. Its probability is σ(0.5255)≈0.6285. The target is one, so this untrained prediction is plausible but uncertain.

2. Send responsibility backward

The forward pass stores intermediate values because the backward pass needs them. For binary cross-entropy with a sigmoid output, the derivative with respect to the output logit is especially simple: δ₂ = p−y, where p is the predicted probability and y is the target. This quantity says how a small movement of the logit changes the loss.

Each output weight vⱼ multiplied hidden activation hⱼ, so ∂ℓ/∂vⱼ = δ₂hⱼ. The output bias has derivative δ₂. A hidden activation influenced the loss through its output weight, giving ∂ℓ/∂hⱼ = δ₂vⱼ. The sigmoid derivative is σ′(z)=σ(z)(1−σ(z)); using the stored output hⱼ gives the hidden pre-activation signal δ₁ⱼ = δ₂vⱼhⱼ(1−hⱼ). Finally, ∂ℓ/∂wⱼₖ = δ₁ⱼxₖ and ∂ℓ/∂bⱼ = δ₁ⱼ.

δ₂=p−y;   ∂ℓ/∂vⱼ=δ₂hⱼ;   δ₁ⱼ=δ₂vⱼhⱼ(1−hⱼ);   ∂ℓ/∂wⱼₖ=δ₁ⱼxₖ

Here j selects one of two hidden units and k selects one of two inputs. ℓ is one example’s loss; L is the mean of those losses over four examples. We first sum every example’s contribution, then divide gradients by four. Averaging keeps the update scale comparable when the batch size changes.

Continue the same row backward

For p≈0.6285 and y=1, δ₂≈−0.3715. The first output-weight contribution is −0.3715×0.6900≈−0.2563. For hidden unit zero, δ₁₀≈−0.3715×0.8×0.6900×0.3100≈−0.0636. Because x=(1,0), this row contributes −0.0636 to the first input weight and zero to the second. The same calculation runs for every row before one simultaneous update.

Complete the second hidden path too. Its output weight is −0.6 and h₁≈0.3775, so δ₁₁≈(−0.3715)×(−0.6)×0.3775×0.6225≈0.0524. This row therefore contributes +0.0524 to W₁[1,0], zero to W₁[1,1], and +0.0524 to hidden bias one. The sign differs from hidden unit zero because its output weight is negative. Backpropagation assigns responsibility through the actual connections; it does not simply copy the output error to every earlier parameter.

Do not update the output weights before computing hidden gradients. Hidden signals depend on the weights used in the forward pass. Mutating them early mixes two parameter states inside one derivative. The reference accumulates all nine gradients first and changes parameters only afterward.

3. Keep the objective and arithmetic honest

Computing −y ln p − (1−y) ln(1−p) directly can take the logarithm of a rounded zero when a logit is large. The project evaluates the equivalent expression max(z,0)−zy+ln(1+e−|z|). It stays finite for large positive or negative logits and has derivative σ(z)−y. The reported loss and the backward formula therefore describe the same objective even at extremes.

Backpropagation is efficient, but a plausible formula can still contain a missing factor or wrong index. A central-difference check perturbs one parameter by h=10−5, computes [L(θ+h)−L(θ−h)]/(2h), and compares that numerical slope with the analytical gradient. The reference checks an output-layer weight and a hidden-layer weight. This does not prove every line correct, but it crosses both chain-rule stages.

The hidden sigmoid can saturate: when |z| is large, h approaches zero or one and h(1−h) approaches zero. Gradients reaching earlier layers then shrink. XOR is small enough for sigmoid, but this failure motivates other activations later. Initialization also matters because two hidden units with exactly identical parameters receive identical gradients and remain identical; they cannot learn two different features.

The deterministic starting values are deliberately asymmetric, which makes the reference repeatable while allowing the hidden units to specialize. One unit can become active for one diagonal arrangement and the other for another. These exact nine values are not universally good. Larger networks normally draw independent weights from a distribution scaled to layer width, then record the seed so a failed run can be reproduced.

Training success is narrow evidence.

Four exact rows prove that the implementation can represent and fit XOR. They do not establish robustness to noisy inputs or generalization to a larger problem. XOR is a mechanism check, not a benchmark.

4. Run the complete Rust network

The reference checkpoint stores fixed-size arrays because every shape is known: w1[hidden][input], b1[hidden], w2[hidden], and one output bias. forward returns the hidden activations, output logit, and probability. step performs full-batch backpropagation, and train repeats it.

cargo test --manifest-path projects/ch07/Cargo.toml
cargo run --release --manifest-path projects/ch07/Cargo.toml

The default trains for 10,000 small steps at learning rate 1.0. Illustrative output shows mean binary cross-entropy below 0.02 and probabilities near zero, one, one, zero in truth-table order. Exact last digits may vary with floating-point implementation, so the test checks the loss threshold and classifications rather than bitwise output.

Read the loops beside the equations. gw2[j] += dz2*h[j] is ∂ℓ/∂vⱼ. The hidden line multiplies by the old output weight and sigmoid slope. The innermost update multiplies by input xₖ. Only after all examples does scale = rate / 4 turn sums into mean-gradient updates.

Debugging: both hidden units stay equal

A learner initializes every weight and bias to zero. Loss changes, but both hidden units remain identical and XOR never separates. Why?

Answer

The units begin with identical inputs and parameters, so they produce identical activations and receive identical gradients. Gradient descent preserves the symmetry. Give their weights different small deterministic starting values; random initialization is a common way to do this in larger networks.

Transfer: replace sigmoid hidden units

Use the hyperbolic tangent, tanh(z)=(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ), for the hidden layer while keeping the sigmoid output and binary cross-entropy. Rust provides z.tanh(); the formula explains the function rather than prescribing a numerically stable implementation. Derive the one changed factor and predict what range hidden features now occupy.

Worked answer

tanh outputs values in (−1,1), and its derivative from stored output h is 1−h². Replace h(1−h) in δ₁ with 1−h². The output formulas remain unchanged. Retune the learning rate only after checking a hidden gradient numerically.

XOR’s positive corners are diagonal and cannot occupy one half-plane. Sigmoid bends the mapping between dense layers. Sigmoid and binary cross-entropy combine to derivative p−y. Hidden gradients require the forward-pass output weights. Symmetric units see the same computations and updates until different initialization breaks that symmetry.
