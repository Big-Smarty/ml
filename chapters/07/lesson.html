Why does a straight boundary fail on four examples?

Two switches control a warning. The warning should be on when exactly one switch is on. You already know how to fit a classifier; now its errors tell us that the model itself must change.

Run just lab 07 before editing. The working baseline learns an output classifier over two fixed, untrained hidden features. It reports all four predictions and its loss. Its limitation is deliberate: the internal features never adapt. A constant probability of 0.5 gives mean binary cross-entropy ln 2 ≈ 0.6931. Compare that honest starting point with the run; successful execution alone does not show that XOR was learned.

XOR, or “exclusive or,” returns one when exactly one input is one. Its four examples are (0,0)→0, (0,1)→1, (1,0)→1, and (1,1)→0. Plot the inputs as corners of a square. A linear classifier predicts from z = w₀x₀ + w₁x₁ + b and places one class on each side of the line z = 0. Whichever line you choose, it cannot isolate two diagonal corners from the other two.

This is a limitation of the model family, not the optimizer. More iterations cannot make a straight boundary bend. Regularization cannot add missing expressive power. The smallest useful repair is a hidden layer: intermediate neurons whose outputs become features for the final neuron.

Our network has two inputs, two hidden neurons, and one output. Dense connections give it four input-to-hidden weights, two hidden biases, two hidden-to-output weights, and one output bias. The hidden neurons apply a sigmoid nonlinearity σ(z)=1/(1+e−z). Without this nonlinear function, composing two dense layers would collapse into another straight line.

A forward pass with numbers

Take input x=(1,0). For the first hidden neuron use weights (0.7,−0.4) and bias 0.1. Its pre-activation is z₀=0.7×1−0.4×0+0.1=0.8, so h₀=σ(0.8)≈0.6900. The second has weights (−0.2,0.9) and bias −0.3: z₁=−0.5 and h₁≈0.3775. With output weights (0.8,−0.6) and bias 0.2, the output logit is 0.8×0.6900−0.6×0.3775+0.2≈0.5255. Its probability is σ(0.5255)≈0.6284. The target is one, so this untrained probability favors class one but remains uncertain.

Before continuing, retrieve the roles of a logit and probability from Chapter 04. A logit is an unrestricted score; sigmoid converts it to a number between zero and one. Predict what changes if the hidden sigmoid is replaced by the identity.

Reasoning

Substituting the first affine calculation into the second only produces new coefficients and a new bias. Two affine layers remain one affine classifier. More parameters alone do not resolve XOR.

How does one error reach all nine parameters?

The forward pass stores intermediate values because the backward pass needs them. For binary cross-entropy with a sigmoid output, the derivative with respect to the output logit is especially simple: δ₂ = p−y, where p is the predicted probability and y is the target. This quantity says how a small movement of the logit changes the loss.

Each output weight vⱼ multiplied hidden activation hⱼ, so ∂ℓ/∂vⱼ = δ₂hⱼ. The output bias has derivative δ₂. A hidden activation influenced the loss through its output weight, giving ∂ℓ/∂hⱼ = δ₂vⱼ. The sigmoid derivative is σ′(z)=σ(z)(1−σ(z)); using the stored output hⱼ gives the hidden pre-activation signal δ₁ⱼ = δ₂vⱼhⱼ(1−hⱼ). Finally, ∂ℓ/∂wⱼₖ = δ₁ⱼxₖ and ∂ℓ/∂bⱼ = δ₁ⱼ.

δ₂=p−y;   ∂ℓ/∂vⱼ=δ₂hⱼ;   δ₁ⱼ=δ₂vⱼhⱼ(1−hⱼ);   ∂ℓ/∂wⱼₖ=δ₁ⱼxₖ

Here j selects one of two hidden units and k selects one of two input features. ℓ is one example’s loss; L is the mean of those losses over N supplied examples. For the XOR fixture N=4. gradient(data) divides every accumulated parameter derivative by N before returning, so it describes the same mean reduction as loss(data). Averaging keeps the update scale comparable when the batch size changes.

Continue the same row backward

For p≈0.6284 and y=1, δ₂≈−0.3716. The first output-weight contribution is −0.3716×0.6900≈−0.2564. For hidden unit zero, δ₁₀≈−0.3716×0.8×0.6900×0.3100≈−0.0636. Because x=(1,0), this row contributes −0.0636 to the first input weight and zero to the second. The same calculation runs for every row before one simultaneous update.

Complete the second hidden path too. Its output weight is −0.6 and h₁≈0.3775, so δ₁₁≈(−0.3716)×(−0.6)×0.3775×0.6225≈0.0524. This row therefore contributes +0.0524 to W₁[1,0], zero to W₁[1,1], and +0.0524 to hidden bias one. The sign differs from hidden unit zero because its output weight is negative. Backpropagation assigns responsibility through the actual connections; it does not simply copy the output error to every earlier parameter.

Do not update the output weights before computing hidden gradients. Hidden signals depend on the weights used in the forward pass. Mutating them early mixes two parameter states inside one derivative. The reference stores all nine mean derivatives in Gradient { hidden_weights, hidden_bias, output_weights, output_bias }, then step subtracts learning_rate * gradient from the matching fields of a new Net. The gradient value is a description of the old parameters, not the new parameters themselves.

We now have the full algorithm, rather than a separate rule for each example. A gradient buffer has the same shapes as its parameters: W₁ [2,2], b₁ [2], W₂ [1,2], b₂ [1]. The output is scalar, so the source omits the length-one dimension of W₂ and b₂. This is a fixed small network; general arrays wait until Chapter 09.

Threshold transfer

When both hidden thresholds are 1.5, their activations are equal on every row. Their difference is zero; the output logit becomes −4 for every input. This returns the network to a constant classifier even though it still contains nonlinear units. Capacity exists in the model family, but a particular parameter state need not use it.

How do you distinguish a bad gradient from a hard training run?

Computing −y ln p − (1−y) ln(1−p) directly can take the logarithm of a rounded zero when a logit is large. The project evaluates the equivalent expression max(z,0)−zy+ln(1+e−|z|). It stays finite for large positive or negative logits and has derivative σ(z)−y. The reported loss and the backward formula therefore describe the same objective even at extremes.

Backpropagation is efficient, but a plausible formula can still contain a missing factor or wrong index. A central-difference check perturbs one parameter by h=10−5, computes [L(θ+h)−L(θ−h)]/(2h), and compares that numerical slope with the analytical gradient. The lab checks every output-layer and hidden-layer parameter, including both kinds of bias. This does not prove every line correct, but it crosses both chain-rule stages.

The hidden sigmoid can saturate: when |z| is large, h approaches zero or one and h(1−h) approaches zero. Gradients reaching earlier layers then shrink. XOR is small enough for sigmoid, but this failure motivates other activations later. Initialization also matters because two hidden units with exactly identical parameters receive identical gradients and remain identical; they cannot learn two different features.

The deterministic starting values are deliberately asymmetric, which makes the reference repeatable while allowing the hidden units to specialize. One unit can become active for one diagonal arrangement and the other for another. These exact nine values are not universally good. Larger networks normally draw independent weights from a distribution scaled to layer width, then record the seed so a failed run can be reproduced.

Training success is narrow evidence.

Four exact rows prove that the implementation can represent and fit XOR. They do not establish robustness to noisy inputs or generalization to a larger problem. XOR is a mechanism check, not a benchmark.

Use the tolerance literally: a derivative a agrees with a numerical slope n when |a−n| ≤ 10⁻⁶ + 10⁻⁴|n|. The absolute term handles derivatives near zero; the relative term scales for larger values. Check before long training and away from saturated hidden units, where both numbers can be tiny without providing a strong test.

How to interpret the results

The smaller rate commonly moves more slowly, but rate alone does not determine the final fit. Comparing fresh copies isolates that factor. At [0.5,0.5], the Boolean truth table does not supply a target; the network is extending its learned surface, not recovering a defined Boolean answer. A high or low probability there is not automatically a mistake. To claim noise robustness, define noisy inputs and their desired labels independently before evaluating them.
