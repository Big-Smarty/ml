What does a derivative say about one error?

Start with just input x = 2 and target y = 5. At w = 0, b = 0, the prediction is 0 and the error e is −5. The squared error is 25. Increasing w by 0.01 changes the prediction to 0.02 and the squared error to 24.8004. The interval slope is (24.8004−25)/0.01 = −19.96. As the interval becomes smaller, that slope approaches −20.

A derivative is this limiting local rate of change. It is not the change caused by an arbitrary large jump. The small triangle Δ in ΔL means “change in L”; dL/dw names the limiting loss change per unit change in w. Because our loss also depends on b, we write ∂L/∂w to say that b stays fixed. This is a partial derivative.

We can find the limiting result using multiplication. If the error changes from e to e+δ, the square changes by (e+δ)²−e² = 2eδ+δ². Dividing by δ gives 2e+δ, which approaches 2e. At e = −5, the square's slope with respect to error is −10. Changing w by a small amount changes e by twice that amount because x = 2. Multiply the two sensitivities: −10 × 2 = −20.

This multiplication is the chain rule: the outer square changes through the inner prediction. Changing the bias instead changes the prediction one-for-one, so its derivative is −10 × 1 = −10. A negative value means a small increase in that parameter lowers this example's error.

For x = −1, y = −1 and the zero model, predict both signs before calculating.

Worked answer

The error is +1. The square contributes 2; the input contributes −1, so the weight derivative is −2. The bias derivative is +2. Raising the weight lowers the prediction for a negative input, helping this row; raising the bias makes its already excessive prediction worse.

How do five examples vote on two slopes?

Training minimizes the average error across every row. The derivative of a sum is the sum of its derivatives; dividing loss by N also divides the derivative by N. For example i, eᵢ = wxᵢ+b−yᵢ. Thus:

gw = (2/N) Σᵢ eᵢxᵢ; gb = (2/N) Σᵢ eᵢ

N counts examples, and i visits their indices. The weight derivative includes xᵢ because weight multiplies the input. The bias derivative does not. Both components form the gradient and describe the same unchanged model.

Browser arithmetic illustrates the same exact fixture; it does not execute Rust. The curve and finite-difference slope guide concern weight only; the text also reports the bias component.

Central differences approximate smooth derivatives; rounding adds error. In this quadratic, central differences are exact in ideal real arithmetic for any nonzero h. In floating point, tiny h can make w+h indistinguishable from w, or cause almost equal losses to round to the same value. More complex smooth losses also have approximation error when h is too large. There is no universally best probe distance.

The Rust check accepts |analytical−numerical| ≤ 10⁻⁶ + 10⁻⁴ max(|analytical|, |numerical|). Absolute tolerance handles values near zero, where a percentage is meaningless; relative tolerance allows proportionate error for larger derivatives. These are f64 teaching tolerances on small smooth inputs, not a universal rule for GPUs or nondifferentiable functions.
