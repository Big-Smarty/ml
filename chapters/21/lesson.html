If z=a+b receives derivative g, what do a and b receive? What changes if a ReLU follows the addition?

Answer

Both operands receive g. A following ReLU first multiplies g by one for a positive pre-activation or zero for a negative one. A shortcut placed before a blocking ReLU is not an unconditional gradient highway.

Our block computes:

y=ReLU(x+αF(Norm(x)))

The input x, learned branch F and output y each have shape [66], stored as 36 row-major values. Norm standardizes one image; F is one padded 3×3 convolution; α is a learned scalar that scales the branch. Two blocks are followed by a dense [236] head and two class logits. All gradients use the same old parameter state before one update per image.

At one location, let x=0.60, F=−0.25 and α=0.20. The sum is 0.60+0.20×(−0.25)=0.55, so ReLU retains 0.55. An incoming derivative 0.8 gives a direct input contribution 0.8, a branch derivative 0.8×0.20=0.16, and an α derivative 0.8×(−0.25)=−0.20. The branch also returns another contribution to the input through its convolution and normalization.

“Residual” here means an architectural correction, not prediction minus target from regression. Elementwise addition needs matching shapes. A projection can adapt a shortcut when channel count or resolution changes, but that is a learned mapping rather than a pure identity. Our same-shape blocks need none.

Which values should supply the mean and variance?

Two images can depict the same bar at different brightness scales. Centering subtracts the average. Standardization also divides by the standard deviation, making scale more comparable within the learned branch. The axis over which these normalization statistics are calculated defines the operation; saying only “normalize the tensor” leaves the method ambiguous.

The lab normalizes all N=36 pixels of one image. With xj the pixel at index j, its mean is μ=∑xjN and its variance is v=∑(xj−μ)2N. The normalized value is yj=(xj−μ)(v+ε), with ε=10−5. This is population variance over the specified computational axis, not the N−1 estimator used in some statistical inference. The cached inverse standard deviation is q=1(v+ε).

For [1133], μ=2 and deviations are [−1−111]. Variance is (1+1+1+1)4=1. Therefore q=11.00001≈0.999995 and the normalized values are approximately [−0.999995−0.9999950.9999950.999995]. For [5555], every deviation is zero; q is finite and every normalized value is zero.

Batch normalization, by contrast, computes training statistics across examples and usually spatial positions for each channel; inference uses saved running statistics. With sample-at-a-time updates we use per-image normalization, without learned affine scale/offset in that operation. It is closer to an instance-style calculation, not an implementation of batch normalization. Statistics are recomputed per image during both fitting and evaluation.

The identity route still carries the original x, so normalizing only the branch does not make the whole network insensitive to brightness. Predict which of the two routes changes if every input value is multiplied by ten. Epsilon also means standardization is not exactly scale invariant when the variance is tiny.

Why does one pixel influence every normalized output?

Retrieve the chain rule for a shared intermediate. Here every pixel contributes to the mean, and every deviation contributes to the variance. Perturbing one xj therefore changes the denominator and centering used by all outputs. A backward rule that merely multiplies each incoming derivative by q ignores those shared paths.

Let gj be the derivative arriving at normalized output yj. Define A=∑gj and B=∑gjyj, both over all N=36 pixels of this image. The input derivative is:

q(gj−AN−yjBN)

The first term differentiates the direct scaled deviation; the second removes the shared mean contribution; the third accounts for variance. This form remains valid for the stated epsilon inside the square root.

Temporarily ignore epsilon in the earlier [1133] example: y=[−1−111], q=1. Let g=[1000]. Then A=1 and B=−1. The four input derivatives are [1−(14)−(14)0−(14)−(14)0−(14)+(14)0−(14)+(14)]=[0.5−0.500]. A derivative entering just one output affects two inputs appreciably. With epsilon included the last two values are tiny rather than exactly zero.

When all incoming gradients equal one, the output sum is always zero, so its input derivative is approximately zero too. That is a useful property check. It complements coordinate finite differences: properties can catch a missing mean path without depending on one chosen input.

Can the shortcut hide a broken learned branch?

A model's loss falls and its output is finite, but a first-block coefficient never changes. The developer points to the shortcut as proof that gradients flow. Explain why that argument is incomplete.

Diagnosis

The shortcut allows a direct route around the branch; it does not prove that the branch itself receives derivatives. A broken normalization backward can leave a useful identity path and head while blocking part of learned feature formation. Check a coefficient in the first branch against the final loss. Also inspect whether ReLU has disabled the tested location.

For a matched scalar comparison, a plain two-layer linear branch with derivatives 0.1 and 0.1 passes an incoming derivative multiplied by 0.01. Two active residual sums with branch derivative 0.1 have factors 1.1 and 1.1, giving 1.21. This arithmetic illustrates a direct route; it does not promise the same improvement in an arbitrary nonlinear network. α, normalization, activation masks and data all change the actual factors.

Which changes are allowed to keep a label?

The classifier distinguishes a vertical bar from a horizontal bar. Small translations usually preserve that label. A 90-degree rotation exchanges the classes. Augmentation is therefore a task claim: the training pipeline presents a changed view but asks for the same answer. It cannot be chosen by assuming that more variation is always beneficial.

Training requests five shifts per base image: up, left, unchanged, right and down. With two labels and two thicknesses, this produces 2×2×5=20 requested views. The supplied learner baseline's translate returns the original image for every request, so its twenty rows contain repeated canonical views. Your implementation will make those requests produce actual zero-padded translations.

Validation uses four dimmed and perturbed canonical images. Their arrays differ from training, but both sets arise from the same four source patterns. This is a functional perturbation experiment, not an independent-source generalization study. With real source objects, split them before generating training augmentations; otherwise near-duplicate views can cross the boundary and make validation optimistic.
