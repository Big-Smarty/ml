How do blank readings become model inputs?

Training temperatures [2,4,100,missing] have observed median 4. Imputing the missing entry with 4 produces [2,4,100,4], whose mean is 1104=27.5. Mean imputation would instead insert 1063≈35.33. These are different modeling decisions; neither discovers the true missing reading.

For median imputation, sort observed finite training values. An odd count uses the middle element; an even count averages the two central elements with midpoint, avoiding overflow from adding extreme finite values. Reject an entirely missing training column because this policy has no median to estimate.

Then fit numeric centering and scale from the imputed training values. Population variance is the mean squared deviation from the fitted mean; scale is its square root. A constant column uses scale one, preserving a finite fixed-width representation. Transform later values with (value−mean)scale and never refit. The missingness indicator remains separate: observed 4 and imputed 4 share their numeric value but differ in the indicator.

Which column means “loaded”?

One-hot encoding represents a category by a vector with one active entry and zero in the others. The active position follows a stored training vocabulary, so the same category retains the same position on later rows.

Recall that a numeric difference is meaningful for a measurement, but regime names have no inherent order. Coding idle=0, loaded=1 and turbo=2 would invent equal distances and an ordering. Instead, fit a sorted vocabulary from training rows and give each known regime one binary column.

Training vocabulary [idle,loaded] produces [1,0] for idle and [0,1] for loaded. This lab reserves an unknown bit at fitting time: unseen turbo becomes [0,0,1] across [idle,loaded,unknown]. It does not create a new turbo column while transforming a test row.

The full maintenance feature vector has nine entries: three standardized sensor values, three missingness indicators, two known-category bits and one unknown bit. Labels stay outside it. Stacking the vectors gives a row-major [rows,9] matrix, represented here as one contiguous Vec<f64> per row. If a training fold learns a different vocabulary, that fold still owns its own consistent fitted width.

Can the same fitted state transform a new batch?

A preprocessor is a small fitted model. fit(training_rows) estimates its arrays and vocabulary; transform(&self, row) reads those quantities. This separation lets a validation batch, a later request and a restored model use the same feature meanings. Recomputing means on each batch would move the coordinate system beneath the classifier.

For training values [10,missing,14], median 12 is fitted before seeing a held-out 100. Fitting on [10,14,100] first would produce median 14. The leak uses no held-out label, yet changes a training row. Imputation, category grouping, feature selection, scaling and PCA all obey this same boundary.

Which holdout matches deployment?

Consider four records A/day 1, A/day 2, B/day 1 and B/day 2. A random row split may train on A/day 2 and validate on A/day 1, sharing both machine identity and future information. A grouped split can hold out B entirely but still train and validate over the same days. A temporal split uses earlier days for fitting but may contain machines already seen. They answer different questions.

The lab provides four requested policies. Row holds IDs divisible by 4 and is only a diagnostic. Group holds machines whose ID modulo 3 is 2. Time trains through day 3 and validates on days 5–7 for all development machines. FutureGroup trains machines 0–11 through day 3 and validates machines 12–17 on days 5–7. The fourth matches our question about later readings from new machines. Day 4 is a gap: labels for day 3 become available on day 4 before validation begins.

Rows outside the chosen sides are intentionally unused for that experiment. A helper must not quietly dump excluded future rows back into training to preserve sample size. The final machines 18–23 on days 9–11 are absent from the chapter's development input entirely.
