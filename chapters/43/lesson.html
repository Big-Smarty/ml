A pretrained decoder predicts general text, but an application may need a particular instruction format, vocabulary, or compact deployment model. This chapter runs three real adaptation experiments on the Chapter 36 decoder: full supervised fine-tuning, a zero-initialized low-rank update to its output projection while the base stays frozen, and teacher-student distillation through soft targets.

Milestone

You will see three different objectives fall on deterministic instruction fixtures, verify that LoRA initially changes no output, count its trained parameters, and prove one adapter derivative with finite differences.

1. Supervised fine-tuning continues next-token training

Supervised fine-tuning, or SFT, starts with existing parameters and trains on prompt-response demonstrations. After tokenization, it still uses next-token cross-entropy. “Instruction tuning” describes the data format and desired behavior; it does not create a different gradient rule.

The project first pretrains a base checkpoint for 60 updates on two generic cyclic token sequences. Its SFT pairs are then input [1,2,3] with targets [2,3,4], and [5,6,2] with targets [6,2,3]. The loss averages across the three positions. The reference cycles through both demonstrations, calls the real decoder’s all-parameter loss_and_grad, and applies SGD. Token embeddings, learned positions, attention, normalization, feed-forward weights, and vocabulary projection can all change.

One cross-entropy term

Suppose a position has logits [2,0] and target token 0. Stable softmax gives probabilities about [0.881,0.119]. Cross-entropy is −ln(0.881) ≈ 0.127. The logit gradient p−y is [−0.119,0.119], so an update raises the target logit relative to the other. SFT averages these contributions over supervised positions.

The measured fixture loss falls from 1.3315 to 0.0147. This proves that the small decoder can fit these two demonstrations. It does not establish held-out instruction following, safety, or retention of previous abilities. A useful pretrained checkpoint and separate validation prompts are necessary for a real adaptation claim.

Diagnose training without evaluation.

A learner reports only falling training loss. The model could memorize the two answers or damage unrelated behavior. Preserve a base checkpoint, hold out instruction variants, test previous capabilities, and compare against simply prompting the base model. Training loss answers whether optimization fit the supplied tokens.

2. Change a projection through a low-rank path

Low-Rank Adaptation, or LoRA, freezes a base matrix W₀ and learns a structured update. Our Chapter 36 output projection is stored [D,V], with model width D and vocabulary size V. We represent ΔW = AB, where A has shape [D,r] and B has shape [r,V]. The effective projection is W = W₀ + (α/r)AB.

Some papers write BA because they choose the opposite matrix orientation. Shapes settle the issue: [D,r] times [r,V] produces [D,V]. The rank of a matrix counts independent directions it can represent. Every column of AB is a combination of the r columns of A, so its rank is at most r; the update cannot independently change every possible direction when r is small. This is a restriction on the change, not a claim that W₀ itself has low rank. Here r is smaller than D and V. The base projection has DV parameters; the adapter has Dr+rV. With D=8, V=8, r=2, it trains 16+16=32 numbers instead of the decoder’s 784 base parameters.

Zero initialization and a 2×2 update

Let W₀=[[1,2],[3,4]], A=[[1],[−1]], and B=[[0,0]]. Then AB is exactly zero, so inserting the adapter preserves W₀. After training changes B to [0.1,0.2], AB=[[0.1,0.2],[−0.1,−0.2]]. With α/r=1, add that matrix to W₀. Initializing one factor to zero preserves the base function while the other nonzero factor allows the first gradient to reach the zero factor.

The project initializes A to small deterministic values and B to zeros. It builds a temporary effective decoder for each step, obtains the gradient G = ∂L/∂W from the actual full decoder, and applies the chain rule: ∂L/∂A = (α/r)GBᵀ and ∂L/∂B = (α/r)AᵀG. Only A and B update, using both factor gradients computed from the old factors before either changes. The teaching implementation still computes a full decoder backward pass and clones the base, so its 32 trainable values do not demonstrate practical LoRA memory or training-speed savings. A production implementation would freeze unnecessary gradient paths and compute the adapter branch directly. A test compares one derivative with a central finite difference after making B nonzero.

The base parameter slice is copied before training and compared afterward. The adapter’s initial maximum change is zero; its measured fixture loss falls from 1.3315 to 0.0016. This is a real adapter on the decoder’s vocabulary projection, although practical LoRA commonly targets attention projections and may train several modules.

3. Learn a teacher’s distribution

Knowledge distillation trains a student to match probabilities from a teacher. A hard label says only which token won. A soft distribution exposes relative preferences: [0.70,0.20,0.10] says the second token is more plausible than the third.

For teacher probabilities q and student probabilities p at temperature one, soft cross-entropy is L = −Σᵢqᵢ ln pᵢ. Its student-logit gradient is p−q. The reference uses a useful linearity trick because Chapter 36 exposes hard-target gradients. For each vocabulary class i, it asks for the hard-target gradient gᵢ, weights it by qᵢ, and sums Σqᵢgᵢ. Since Σqᵢ=1, this equals the soft-target gradient exactly at temperature one. Soft cross-entropy equals KL(q||p) plus teacher entropy −Σqᵢln qᵢ. That entropy is constant while the student trains, so both objectives have the same student gradient even though their numerical loss values differ.

Combine hard gradients into one soft gradient

Let student p=[0.5,0.5] and teacher q=[0.75,0.25]. The hard gradient for class 0 is [−0.5,0.5]; for class 1 it is [0.5,−0.5]. Weighting gives 0.75[−0.5,0.5]+0.25[0.5,−0.5]=[−0.25,0.25], exactly p−q. The update raises the first student logit.

The teacher is the SFT decoder with width eight. The student has width four, one attention head, and a smaller feed-forward block. On four transfer tokens, measured mean KL divergence at temperature one falls from its initial value to a lower value. KL(q||p)=Σqᵢln(qᵢ/pᵢ) is zero only when distributions match. The implementation subtracts teacher and student log-softmax values directly, then weights by teacher probabilities. It never clips the student probability to a floor: clipping would change the reported divergence for a confidently wrong student. A central-difference check also verifies the weighted soft-target gradient against the direct soft cross-entropy.

Temperature T greater than one produces softer probabilities from logits/T. Then derivatives include temperature factors, and common distillation objectives multiply the soft loss by T² when combining it with hard-label loss. This executable stays at T=1 so its weighted hard-gradient construction and reported KL optimize the same distribution. It performs V backward passes per example; that clear method is suitable only for the eight-token teaching vocabulary.

4. Choose the adaptation boundary

Full SFT spends updates on every parameter and can express broad changes, but it stores a full model checkpoint per adaptation and can overwrite useful behavior. LoRA stores a small task-specific delta and preserves one shared base, but rank and target modules constrain what it can learn. Distillation changes the deployed architecture: the student can be smaller and may be faster depending on implementation and hardware, but matching a teacher is an optimization problem with its own transfer data.

These techniques can be combined. An SFT model can become a teacher. A LoRA adapter can teach a smaller student. The clean comparison keeps training examples, evaluation prompts, tokenization, and metrics fixed. Count trainable parameters and checkpoint bytes separately from runtime, because a low-rank training representation may be merged into a dense matrix for inference.

Data quality sets the behavior being copied. Demonstrations can contain errors or narrow preferences; teacher probabilities can be confidently wrong. Fine-tuning does not verify factual truth. Track dataset provenance, inspect failures, and reserve evaluation items that did not influence training choices.

The pretrained base in this chapter has learned only two tiny synthetic cycles; it is not a useful language model. It does make the adaptation boundary real: SFT and LoRA begin from an already trained checkpoint and use different demonstrations. The decoder averages loss over the complete sequence. Production instruction tuning often masks prompt-token loss and trains only response positions; adding a loss mask is a useful extension.

Debugging · Neither factor changes

A learner initializes both A and B to zero. Explain why training stalls.

Answer

∂L/∂A contains B and ∂L/∂B contains A. If both are zero, both gradients are zero. Initialize one factor to nonzero small values and the other to zero so ΔW starts at zero but a gradient path exists.

Independent variation

For a [384,256] projection, compare rank 4 and rank 16 adapter counts and fractions of the 98,304 dense parameters.

Answer

Rank 4 uses 384×4+4×256=2,560, about 2.60%. Rank 16 uses 10,240, about 10.42%. Higher rank increases capacity and storage; only evaluation can say whether it helps.
