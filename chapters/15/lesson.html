Which question separates a mixed node?

A decision tree can ask “is vibration above this threshold?” and then ask a different question within each resulting group. That makes interactions possible without assuming that all failures form one Gaussian cloud or lie near one global center.

The learner baseline is a working median stump, an ensemble of identical stumps and a global-mean regressor; none is being passed off as the completed mechanism.

A node with three negatives and one positive has positive fraction p=1/4. Its Gini impurity is 2 p(1−p)=2×.25×.75=.375. A split separating the three negatives from the one positive leaves two pure children, weighted impurity 0. A second split into[two negatives, one positive] and[one negative] yields(3/4)×(4/9)+(1/4)×0=1/3.

Child impurity must be weighted by child row count. The criterion represents the expected impurity after sending a randomly selected parent row to its child. Simply averaging the two child impurities gives a tiny child the same influence as a large one.

For binary labels, Gini is 1−p²−(1−p)². For more classes, subtract every squared class proportion from 1. The new executable is binary; the same principle generalizes, but its label boundary deliberately rejects other values.

Predict a split

For four labels[0,0,1,1] sorted along one sensor, splitting between the middle two gives impurity 0. Splitting after the first row leaves a pure child of size 1 and a mixed child of size 3, weighted impurity 1/3. Neither score is the held-out error rate.

Build the recursive partition

Replace tree's median-on-feature 0 rule with CART-style search and recursion. At each node, enumerate feature columns and midpoint thresholds between sorted distinct training values. Partition rows, calculate weighted child Gini, and keep the lowest-scoring candidate. When no valid split exists, emit a leaf.

A leaf stores the positive fraction among its training rows. Prediction follows one branch at each internal node and returns one leaf value, so the model is piecewise constant. Stop at depth 0, a pure node or an unsplittable node. Depth controls capacity; the depth parameter is not the number of gradient steps.

What changes when trees see different rows?

Retrieve the bootstrap from Chapter 12. From indices[0,1,2,3], a bootstrap[3,0,3,2] repeats row 3 and omits row 1. For bagging, fit one tree on each independently drawn bootstrap and average the leaf fractions. Unlike the statistical bootstrap, the purpose here is to produce a diverse collection of predictors rather than interval endpoints.

A single tree can change sharply when a few training cases change. Averaging useful trees can reduce this variance when their errors are not perfectly correlated. Copying the same tree 15 times produces the same answer and no averaging benefit. The learner's current forest does exactly that, so its output exposes the missing mechanism.

A random forest adds another source of diversity: at every node, draw a fresh subset of candidate features, then search thresholds only within that subset. Selecting features once for the entire tree is a random-subspace method, not the per-node procedure taught here. Sampling all features recovers ordinary bagging with the same tree learner.

A training row absent from a particular bootstrap is out-of-bag for that tree. A prediction aggregated only from trees that omitted it can support an internal error estimate. This lab does not retain bootstrap membership, so it reports explicit held-out metrics and never claims an out-of-bag score.

What should the next tree try to correct?

Bagged trees fit independently. Boosting fits sequentially: each new learner targets what the current ensemble has left wrong. For squared-error targets[0,1,3,4], the best constant prediction is their mean 2. Residuals are target−prediction=[−2,−1,1,2]. A stump splitting the first two from the last two predicts residual means−1.5 and 1.5.

With learning rateη=.2, new predictions are 2+.2×(−1.5)=1.7 on the left and 2+.2×1.5=2.3 on the right. The next stage must recompute residuals from these new predictions. Reusing the first residuals would add the same correction repeatedly and is not gradient boosting.

Earlier gradient code used signed error prediction−target. The boosting residual reverses that sign because the next tree learns a correction. For MSE, the negative derivative with respect to prediction is 2(target−prediction)/n. Fitting residuals gives the same direction up to the common positive scale. More generally, gradient boosting fits a weak learner to the negative derivative of the chosen loss.

After m stages, Fm(x)=F(m−1)(x)+ηhm(x). Here F is the ensemble, h is the new stump andη is the step size. The lab retains squared-error regression so each correction is visible; it does not implement logistic-loss boosting or claim that a raw regression score is a calibrated failure probability.

Fit a complete residual stage

Replace boost's mean-only return with a stage loop. Start from initial_boost, which validates paired numerical targets and stores their mean. Each round computes residuals, fits one regression stump, updates every training prediction, and saves the stump for inference.

For a regression stump, leaf values are mean residuals and the split criterion is residual sum of squared errors. It is not Gini. Compare candidate thresholds using the sum of (residual−leaf_mean)² over all rows. A constant-feature table has no split, so its best stage is a single mean-residual leaf.

fn forest_predict(trees: &[Tree], features: [f64; 2]) -> usize {
    let ones = trees
        .iter()
        .filter(|tree| tree.predict(features) == 1)
        .count();
    (ones * 2 >= trees.len()) as usize
}
