How much independent variation is in three sensors?

Temperature and vibration both respond to wear, so three sensor columns need not contain three independent directions of information. PCA finds directions that preserve variation while allowing fewer stored coordinates. It does not use failure labels, and a high-variance direction need not be the most predictive one.

Which direction keeps the most variance?

For C=[2112], multiplying q1=[1,1](2) gives 3⁢q1. Multiplying the perpendicular q2=[1,−1](2) gives 1⁢q2. These are eigenvectors: the matrix scales them without rotating them. Their eigenvalues 3 and 1 are the sample variances of projected coordinates along those unit directions.

The total variance is the trace 2+2=4, also 3+1. Keeping q1 retains 34=75%. A centered point [2,0] has projection coordinate q1⋅x=(2). Reconstructing from that one coordinate gives (2)×q1=[1,1], losing the difference direction.

For a unit direction q, projected variance is qT⁢C⁢q. PCA maximizes it subject to qT⁢q=1; the maximizing direction is a leading covariance eigenvector. A direction and its negative span the same axis. The sign of a printed component is arbitrary, so compare absolute dot products or reconstruction results rather than insisting on a sign.

Before implementing iteration, predict the leading direction for C=[3001] and for the correlated matrix above. The first favors the first axis; the second favors a diagonal. Selecting the largest individual diagonal entry cannot solve both.

Recover a direction through repeated multiplication

Start with v=[1,0] and C=[2112]. The product is [2,1]. Normalize it by 5 to obtain the next unit direction. Its Rayleigh estimate vT⁢C⁢v is 145=2.8. Another step points along [5,4] and estimates 12241≈2.9756; the leading eigenvalue is 3.

Power iteration repeatedly multiplies and normalizes. If the start overlaps the leading direction and the largest eigenvalue magnitude is unique, that component grows relative to the others. Never update the first coordinate of v before computing the second output: construct a separate next vector so both products use the old state.

Replace the first retained coordinate axis in fit with power iteration. Normalize every step, reject nonfinite arithmetic and handle a zero product explicitly. Compute the final Rayleigh quotient. How do several coordinates reconstruct a row?

A single component turns d features into one number. For k components, store k unit directions and calculate one dot product per direction. This lab stores directions as k rows of a matrix Q[k,d], so scores=Q⁢(x−μ), shaped [k]. Reconstruction is μ+QT⁢scores, shaped [d]. Many texts store components as columns instead; the transpose changes because the layout changes, not because the geometry changes.

The supplied Pca::transform and reconstruct implement those two operations and validate widths. The reconstruction metric sums all squared coordinate residuals for a row, then averages across rows. Its denominator is n, not n×d. This is a mean squared Euclidean reconstruction norm, not coordinate MSE.

fn fit(rows: &[Vec2]) -> Result<Self, &'static str> {
    let mean = mean(rows)?;
    let covariance = covariance(rows, mean)?;
    // Constant data has no distinguished direction: choose the first axis.
    let (mut component, eigenvalue) = if covariance.iter().flatten().all(|&x| x == 0.0) {
        ([1.0, 0.0], 0.0)
    } else {
        power_iteration(covariance, 40)?
    };
    if component[0] < 0.0 {
        component = [-component[0], -component[1]];
    }
    Ok(Self {
        mean,
        component,
        eigenvalue,
        covariance,
    })
}

Keep new components independent of earlier ones

After finding q1, running ordinary power iteration again tends to rediscover q1. To find the next component, remove already-retained directions. Deflation can replace C by C−λ1⁢q1⁢q1T. The solution instead projects each product away from the earlier components: for each previous q, subtract (v⋅q)⁢q. Both express the need to work in the orthogonal remainder.

Extend your fitting loop to retain k components. Orthogonalize a fresh starting vector against earlier directions, normalize, and repeatedly multiply by the original covariance followed by the same orthogonalization. Try several starts in the remaining space. Store each component and its Rayleigh value. Constant or rank-deficient data may have valid zero-variance remaining axes.

Hint: do not divide by an eigenvalue to project

Projection onto a unit direction is a dot product. Dividing by a small eigenvalue is a whitening operation with a different meaning and numerical risk.

When can a correct answer still wobble?

For positive covariance eigenvalues 3 and 1, the condition number is 31=3. If they are 3 and .000003, it is one million. A nearly flat direction is excellent for compression but hazardous for operations that divide by its variance. An exact duplicate feature creates a zero eigenvalue and infinite condition number.

A nearly tied pair of leading eigenvalues causes a different problem. Many axes preserve almost the same variance, so a tiny data change can rotate an individual reported eigenvector. The combined subspace may remain stable. The eigengap, the difference between neighboring eigenvalues, helps explain this sensitivity.

Forming ZT⁢Z squares the condition number of the centered data matrix Z. Production PCA often uses singular-value decomposition of Z rather than explicitly forming covariance. Our covariance/power implementation is bounded and inspectable; it is not a robust general eigensolver. Fixed iteration counts do not guarantee convergence for near-tied eigenvalues.

Raw versus standardized PCA is also a modeling decision. Standardizing gives every numeric feature equal initial variance, emphasizing correlation. Raw PCA preserves original units and can be dominated by the numerically largest unit. Fit any scaler on training data, and do not claim one choice is universally correct.
