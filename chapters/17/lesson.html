A table may contain twenty columns without containing twenty independent pieces of information. If two sensors rise together, much of their variation lies along one direction. Principal component analysis finds that direction, projects rows onto it, and shows both the promise and the numerical hazards of linear algebra on data.

Your milestone

You will center two correlated measurements, build their covariance matrix, find its leading eigenvector with power iteration, compress each row to one number, reconstruct it, and interpret the condition number.

1. Turn correlated columns into a matrix

Chapter 16 used a weight vector to choose a separating direction. Here there are no labels. We seek a direction that preserves as much variation in the feature rows as possible. Begin with n rows xᵢ, each containing d features. Their mean vector μ contains one mean per feature: μ = (1/n)Σᵢxᵢ. The centered row is zᵢ = xᵢ − μ.

Centering matters because principal component analysis, or PCA, describes variation around the dataset's center. Without subtraction, a large offset from the origin can dominate the direction even when every row shares that offset. Fit the mean from training data, store it, and subtract that same mean from later rows.

The sample covariance matrix is

C = (1/(n−1)) ZᵀZ

Z is the n-by-d matrix whose rows are centered examples. C is d-by-d. Entry Cjj is the sample variance of feature j. Entry Cjk measures whether features j and k vary together. A positive off-diagonal value means above-average values tend to coincide; a negative value means one tends to rise while the other falls. Dividing by n instead would give population covariance. It scales every eigenvalue by the same factor and leaves eigenvector directions unchanged, but reported variances would differ. The project consistently uses n−1.

Build covariance by hand

Use three already-centered rows [√2,0], [0,√2], and [−√2,−√2]. Their column means are zero. Multiplying ZᵀZ sums outer products and gives [[4,2],[2,4]]. Divide by n−1 = 2 to obtain C = [[2,1],[1,2]]. The diagonal says both features have variance two; the positive ones off the diagonal say they rise together.

Rust stores each teaching row as [f64; 2] and the covariance as [[f64; 2]; 2]. The nested loops state which row and feature pair contribute to each entry. The implementation rejects fewer than two rows and nonfinite values before division or ordering.

2. Variance chooses an eigenvector

Choose a unit direction q, meaning qᵀq = 1. Project centered row zᵢ onto it with the dot product tᵢ = qᵀzᵢ. The scalar tᵢ is a projection score. The sample variance of all these scores is qᵀCq. PCA chooses q that maximizes this expression while remaining unit length.

The maximizing directions satisfy Cq = λq. Such a q is an eigenvector; multiplying by C changes its length by eigenvalue λ without rotating it. The leading principal component is the eigenvector with the largest eigenvalue because its projected scores have the largest variance.

Find the leading component and retained variance

For C = [[2,1],[1,2]], q₁ = [1,1]/√2 is an eigenvector because Cq₁ = 3q₁. The orthogonal direction q₂ = [1,−1]/√2 has Cq₂ = 1q₂. The total variance is the trace, 2+2 = 4, also equal to 3+1. Keeping q₁ retains 3/4 = 75% of the sample variance.

For centered z = [2,0], the score is q₁ᵀz = 2/√2 = √2. Reconstruction within the one-dimensional subspace is q₁√2 = [1,1]. We compressed two coordinates into one score and lost the discarded difference direction.

For k components, put the eigenvectors into columns of Q. Then t = Qᵀ(x−μ) produces k scores and x̂ = μ + Qt reconstructs d features. Eigenvector signs are arbitrary: q and −q describe the same axis, changing only the signs of scores. Tests should compare their absolute dot product rather than requiring matching signs.

3. Find the direction by repeated multiplication

A general eigensolver hides useful machinery, so the project uses power iteration. Start with a nonzero v. Repeatedly compute Cv and normalize it: v ← Cv / ||Cv||₂. If the starting vector overlaps the dominant eigenvector and the largest eigenvalue magnitude is unique, its contribution eventually overwhelms the others. The Rayleigh quotient λ̂ = vᵀCv estimates the eigenvalue.

Watch the estimate converge

Start at v₀ = [1,0] for C = [[2,1],[1,2]]. Multiplication gives [2,1], so v₁ = [2,1]/√5. Its Rayleigh estimate is 14/5 = 2.8. The next unnormalized direction is proportional to [5,4], giving λ̂₂ = 122/41 ≈ 2.9756. A third produces [14,13] and about 2.9973. The true leading value is three.

let next = mat_vec(covariance, v);
let norm = dot(next, next).sqrt();
v = [next[0] / norm, next[1] / norm];
let eigenvalue = dot(v, mat_vec(covariance, v));

Updating v in place during matrix multiplication is a subtle bug: the second output would use an already-changed first coordinate. The reference builds a separate next vector. It also rejects a zero or nonfinite norm before dividing.

One starting direction can be exactly orthogonal to the dominant eigenvector and never discover it. In this two-dimensional teaching implementation, two independent starts are iterated and the result with the larger Rayleigh quotient is selected. This does not replace a robust general eigensolver, but it fixes the easy two-dimensional blind spot and leaves a runnable invariant: the returned vector has unit norm and a small residual ||Cv−λv||₂.

If a starting vector lies exactly in the covariance matrix’s null space, its first product is zero and cannot be normalized. The reference tries both independent starts and keeps a successful one; it reports an error if neither provides a usable direction for nonzero covariance. A regression check uses rank-one data perpendicular to one seed.

4. Conditioning tells you when answers wobble

An algorithm may be implemented correctly while its answer remains sensitive to small changes in data. The condition number of a positive covariance matrix is λmax/λmin. A value near one means variance is similar in all directions. A large value means at least one direction has tiny variance compared with another.

For C = [[2,1],[1,2]], the condition number is 3/1 = 3. If the eigenvalues were 3 and 0.000003, it would be one million. The latter matrix is nearly rank one. That can be good for compression, yet operations that divide by the small eigenvalue amplify noise. Exact duplicate features make λmin zero and the condition number infinite.

A separate issue arises when leading eigenvalues are nearly tied. Then many directions preserve almost the same variance, and a tiny perturbation can rotate the reported first component sharply. The two-dimensional subspace may be stable even when one named eigenvector is not. Report an eigengap or inspect nearby eigenvalues before assigning a physical story to individual loadings.

Constructing C = ZᵀZ also squares the condition number of Z. If singular values of Z span a factor of 10⁶, covariance eigenvalues span about 10¹². Production PCA therefore usually uses a singular-value decomposition of centered data. Covariance plus power iteration stays here because it exposes every step. Its ceiling is numerical reliability on high-dimensional or badly conditioned data.

Feature standardization is a modeling choice rather than an automatic repair. If one column is measured in millimeters and another in kilometers, raw variance may mostly encode units. Scaling both to unit variance gives them equal initial influence. If physical scale is meaningful, standardization can erase that meaning. Fit any scaling using training data only.

Debugging · Translation changes the component

A learner projects with dot(component, x). Adding [100,−50] to every row changes the scores and reconstructions.

Answer

The projection omitted centering. Use dot(component, x - mean) and add the mean back during reconstruction. Covariance, eigenvalues, reconstruction errors, and component directions should remain unchanged by translating every row equally.

Centering makes directions describe variation around the data rather than offset from the origin. An eigenvalue is the sample variance captured along its eigenvector. Normalization prevents magnitudes from exploding or vanishing and isolates direction. A large condition number signals a near-flat direction where noise can be amplified. Eigenvector sign is arbitrary because both vectors span the same axis.

Retrieve Chapter 3's dot products and feature scaling and Chapter 13's training-only preprocessing. This project handles two features and one component, not generic top-k PCA or production SVD. In Chapter 18, the compressed geometry becomes unsupervised grouping and density estimation.

Constant observations have zero covariance, so no direction is preferred and the usual retained-variance ratio is 0/0. The reference chooses the first coordinate axis, reconstructs every row exactly, and reports a retained fraction of zero by convention. For nonzero data, normalization uses hypot and tests exact zero rather than comparing a dimensional norm with machine epsilon. Changing measurement units must not turn a valid direction into an error. The two-by-two condition calculation first rescales covariance; this avoids making conditioning depend on an absolute cutoff. Forty power steps still do not replace a converged, robust eigensolver for nearly equal eigenvalues.
