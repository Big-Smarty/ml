Chapter 22 summed derivatives from two uses of one encoder. What must happen when a parameter is used once at every time step? And why does a chronological split differ from shuffling independent tabular rows?

Answer

All uses contribute to the same parameter gradient. Sequence observations and overlapping windows are dependent; future observations and near-identical windows can leak across a shuffled split. Order also determines the model's carried state.

A scalar RNN computes h[t]=tanh(wₓx[t]+wₕh[t−1]+b), then predicts ŷ[t+1]=wᵧh[t]+bᵧ. The code names these five parameters input_weight, recurrent_weight, bias, output_weight and output_bias. x[t] is the observed input, h[t] is an internal state, and ŷ[t+1] predicts the next observation. All five parameters are reused at every time.

Let x=2, previous state −1, input weight 0.5, recurrent weight 0.25 and bias 0.1. The affine sum is 1−0.25+0.1=0.85. Tanh gives h≈0.6911. With output weight 0.8 and zero output bias, the prediction is about 0.5529. The previous state changes the answer even though the current input is fixed.

How does a later mistake change an earlier recurrent use?

Backpropagation through time, or BPTT, is ordinary reverse-mode differentiation over the unrolled computation. Imagine one cell copy per time step, with every copy tied to the same parameter values. A hidden state affects its immediate forecast and all later states. Both derivative paths must arrive before its local derivative is finalized.

The loss is ordinary MSE over N=T next-value targets: L=Σ(ŷ[t+1]−x[t+1])²/N. Thus prediction derivative d[t]=2(ŷ[t+1]−x[t+1])/N. Let u be the derivative arriving from the next hidden state. At time t, the derivative before tanh is δ[t]=(d[t]wᵧ+u)(1−h[t]²). Accumulate δ[t]x[t] into wₓ, δ[t]h[t−1] into wₕ and δ[t] into b. Then replace u with δ[t]wₕ before moving one step earlier.

Suppose the immediate forecast contributes 0.3 to a hidden-state derivative and the future contributes 0.2. For h=0.5, tanh's derivative is 1−0.25=0.75, so δ=(0.3+0.2)×0.75=0.375. With recurrent weight 0.4, the prior state receives 0.15. If its old state was −0.2, this use contributes −0.075 to the shared recurrent-weight derivative.

The output parameters also collect every time's contribution: dL/dwᵧ=Σd[t]h[t], and dL/dbᵧ=Σd[t]. All parameter accumulators start at zero once per full sequence. Updating weights inside the backward loop would differentiate some steps with a different model from the one used in forward.

When does repeated multiplication lose the past?

Across several recurrent edges, derivatives multiply by factors wₕ(1−h[t]²). With an effective magnitude 0.4 at each of five steps, a contribution shrinks to 0.4⁵=0.01024 of its starting value. A magnitude 1.5 would grow to about 7.59375 over five steps. Tanh saturation near −1 or 1 reduces its derivative toward zero even when a weight is sizable.

Gradient clipping limits an excessively large gradient norm before an update. It does not restore a vanished long-range contribution. Truncated BPTT stops credit after a chosen window to bound memory and work; it changes the gradient approximation. Our completed RNN uses the full 80-target training prefix, so no truncation policy is hidden.

Can memory have an additive route through time?

An LSTM separates exposed hidden state h from cell memory c. Four functions inspect the current input and previous hidden state. The input gate i, forget gate f and output gate o use sigmoid, producing values between zero and one. The candidate g uses tanh, producing values between −1 and one. Each scalar gate has an input weight, recurrent weight and bias; a linear output head adds two parameters, for fourteen total.

The updates are c[t]=f[t]c[t−1]+i[t]g[t] and h[t]=o[t]tanh(c[t]). Forget controls retained old memory, input controls the proposed addition, and output controls exposed memory. The direct cell path's derivative includes f[t], avoiding a mandatory tanh derivative at every step along that particular path. Gates still depend on state and can saturate; the architecture does not guarantee arbitrary long memory.

With old cell 0.4, forget 0.9, input 0.8, candidate 0.3 and output 0.6, new cell is 0.9×0.4+0.8×0.3=0.60. New hidden state is 0.6×tanh(0.60)≈0.3222. Along the direct cell path, five forget factors of 0.9 retain 0.9⁵≈0.59049 of a gradient, before considering other paths.

The complete supplied Lstm::forward computes all gates and caches their values, previous h/c and new h/c at every time. A stable sigmoid uses 1/(1+exp(−x)) when x≥0 and exp(x)/(1+exp(x)) otherwise, avoiding exponential overflow for large negative inputs. The forget bias begins at one; this is a stated initialization choice, not proof of long-horizon success.

The displayed cell is the modern variant with an adaptive forget gate. The original 1997 LSTM paper established the memory approach; the forget mechanism was introduced later by Gers, Schmidhuber and Cummins. Keeping that distinction makes the source history match the equations actually executed.

Carry both hidden-state and cell-state credit

Your baseline lstm_gradient already differentiates each cell locally, but it detaches state at every step. Extend it to full BPTT by carrying two derivatives from the future: the hidden-state contribution and the cell-state contribution. This is not the same single variable as the RNN's state derivative.

Let dh be immediate forecast derivative×output weight plus future hidden derivative. Let dc be future cell derivative plus dh×o×(1−tanh(c)²). The local gate-output derivatives are do=dh×tanh(c), df=dc×old_c, di=dc×g and dg=dc×i. Sigmoid derivatives multiply by gate×(1−gate); the candidate derivative multiplies by 1−g². Each gate then receives an input-weight, recurrent-weight and bias contribution.

The prior cell receives dc×f. The prior hidden state receives the sum of all four gate pre-activation derivatives times their respective old recurrent weights. Compute and carry both before moving earlier in time. The supplied local gate calculations and caches let you focus on this full temporal connection.

Which targets are genuinely later than fitting?

The chronological split uses observations 0 through 80 for training, providing targets 1 through 80. Validation begins with observation 80 as context and evaluates targets 81 through 120. Thus there are 80 training targets and 40 later targets. The boundary value is shared input context; no later validation target is optimized.

Both teacher-forced validation routines reset state at the boundary and consume actual observed inputs in order. Their errors therefore measure one-step conditional prediction. A persistence baseline predicts the next observed value equals the current one. Slow signals make persistence strong, so a learned model should be compared with it, not merely with random initialization.

After full BPTT, the measured reference values are: persistence validation MSE 0.01390; RNN 0.39891→0.01194; LSTM 0.39095→0.01779.
