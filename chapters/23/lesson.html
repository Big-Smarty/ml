Independent tabular examples can be reordered without changing their meaning. Sequence observations cannot: the previous observation supplies context for the next one, and future observations must not leak into training. Recurrent networks carry a learned state through time. Their gradients travel backward through that state, and their evaluation must travel forward through the calendar.

Your milestone

You will train a scalar recurrent neural network with full backpropagation through time, then train a one-cell LSTM with input, forget, output, and candidate paths. Both fit only the first 80 targets and report teacher-forced one-step error on the next 40, alongside a persistence baseline.

Code and terminology carried forward

Chapter 22 used forward for model outputs and cached intermediate values, then fused an objective with its parameter derivative in loss_and_gradient. Chapter 23 keeps those meanings and the ordinary convention that a prediction precedes its target in loss code. See the course code and terminology guide.

The justified change is the data shape. One scalar sequence values supplies adjacent supervised pairs: values[t] is the input and values[t + 1] is its target. forward consumes the input slice in time order and returns predictions plus the recurrent state cache needed by BPTT. loss_and_gradient returns ordinary mean squared error and its parameter gradient from the same cache; loss returns that same scalar objective. Training mutates these larger models through &mut self and names its chosen step size learning_rate.

1. Let the past change the current calculation

A feed-forward model predicts from a fixed input. A recurrent neural network also receives its previous hidden state. The project uses one scalar state: ht = tanh(wxxt + whht−1 + b), followed by prediction ŷt+1 = wyht + by. In code, these compact symbols are input_weight, recurrent_weight, bias, output_weight, and output_bias.

The same five parameters are reused at every time step. xt is the observed signal now, ht−1 summarizes earlier observations, and ŷt+1 estimates the next observed value. Reuse lets one model accept different sequence lengths, but the single scalar state creates a severe information bottleneck.

Advance one recurrent state

Let xt = 2, ht−1 = −1, wx = 0.5, wh = 0.25, and b = 0.1. The pre-activation is 0.5×2 + 0.25×(−1) + 0.1 = 0.85. Therefore ht = tanh(0.85) ≈ 0.6911. If wy = 0.8 and by = 0, the next-value prediction is about 0.5529.

Order matters because each state depends on its predecessor. Shuffling pairs (xt,xt+1) and resetting state would train a one-lag nonlinear regressor, not the same recurrent computation. Carrying state across unrelated sequences is also wrong. The state should reset at a declared boundary, such as a new machine, patient, or independent recording.

The project signal is sin(0.17t) + 0.25cos(0.043t) for t from 0 through 120. This formula creates a deterministic teaching series. Training receives the generated values, not the formula. Learning a next-step relationship does not mean the network discovered those two frequencies uniquely.

The sequence-to-supervision mapping is explicit in both models:

let target_count = values.len() - 1;
let inputs = &values[..target_count];
let targets = &values[1..];
let cache = self.forward(inputs);

At index t, inputs[t] is exactly values[t], and targets[t] is exactly values[t + 1]. Supplying those true previous values during training is teacher forcing. It concerns the model input sequence; the hidden state still comes from the preceding recurrent computation.

2. Backpropagate through shared time steps

To differentiate the sequence, imagine copying the recurrent cell once for every time step while tying all copies to the same weights. Backpropagation through time, or BPTT, is reverse-mode differentiation over this unrolled graph.

The project averages squared one-step errors over N targets: L = (1/N)Σ(ŷt+1−xt+1)². Here N is values.len() - 1, the number of adjacent targets, rather than the number of stored values. This is ordinary MSE with no factor one half. Thus dL/dŷ = 2(ŷ−x)/N. Each hidden state influences its immediate prediction and, through wh, every later state. In reverse order, combine the prediction contribution with the state gradient arriving from ht+1, multiply by 1−ht² for tanh, accumulate into RnnGradient, and send a new state gradient through wh to ht−1.

See two gradient paths

Suppose the immediate prediction sends gradient 0.3 into ht, the later state sends 0.2, and ht = 0.5. Combined hidden gradient is 0.5. Tanh's local derivative is 1−0.5² = 0.75, so pre-activation gradient is 0.375. If wh = 0.4, the gradient passed to the prior state is 0.15. The recurrent-weight gradient also receives 0.375ht−1.

Repeated factors can shrink when magnitudes stay below one or grow when products exceed one. Tanh also approaches derivative zero when its state saturates near −1 or 1. This produces vanishing or exploding gradients over long intervals. Gradient clipping can limit explosion, and truncated BPTT can bound computation, but neither creates missing long-range information. The tiny reference unrolls the complete 80-target training prefix so no truncation policy is hidden.

All time steps contribute to the same parameter-gradient fields. The local names prediction_gradient, preactivation_gradient, and next_state_gradient are derivatives of intermediate values, while RnnGradient contains derivatives of learned parameters. Updating a recurrent weight while still traversing earlier steps would mix old and new models in one derivative. The implementation first stores every forward state, computes the full reverse pass, and then updates all five parameters simultaneously.

let mut gradient = RnnGradient::default();
let mut next_state_gradient = 0.0;
for t in (0..target_count).rev() {
    let prediction_gradient =
        2.0 * (cache.predictions[t] - targets[t]) / target_count as f64;
    gradient.output_weight += prediction_gradient * cache.states[t + 1];
    gradient.output_bias += prediction_gradient;
    let preactivation_gradient =
        (prediction_gradient * self.output_weight + next_state_gradient)
            * (1.0 - cache.states[t + 1].powi(2));
    gradient.input_weight += preactivation_gradient * inputs[t];
    gradient.recurrent_weight += preactivation_gradient * cache.states[t];
    gradient.bias += preactivation_gradient;
    next_state_gradient = preactivation_gradient * self.recurrent_weight;
}

The fused loss_and_gradient name states that the method returns both quantities and shares forward work. The separate loss method reports the identical target-mean MSE. Neither name changes the objective or its denominator.

3. Give memory a controlled additive path

A long short-term memory cell separates exposed hidden state h from cell memory c. Four functions inspect xt and ht−1. The input gate i, forget gate f, and output gate o use sigmoid and lie between zero and one. Candidate g uses tanh and lies between −1 and one.

ct = ftct−1 + itgt    ht = ot tanh(ct)

Each gate has an input weight, recurrent weight, and bias in this scalar model. A linear output weight and bias produce the forecast, for fourteen learned parameters total. The stable sigmoid computes 1/(1+exp(−x)) for nonnegative x and exp(x)/(1+exp(x)) for negative x, preventing overflow at large negative inputs.

Update one memory cell

Let ct−1 = 0.4, f = 0.9, i = 0.8, candidate g = 0.3, and o = 0.6. New memory is 0.9×0.4 + 0.8×0.3 = 0.36 + 0.24 = 0.60. Hidden state is 0.6×tanh(0.60) ≈ 0.3222. The old-memory derivative through the direct cell path contains f = 0.9, so much of a later cell gradient can survive this step.

LSTM backward carries two state derivatives: a hidden-state gradient and a cell-state gradient. The output gate receives hidden gradient × tanh(c). Cell gradient receives hidden gradient × o × (1−tanh²(c)) plus the cell-state gradient from the future. That cell gradient splits into forget, input, and candidate paths. Their sigmoid or tanh derivatives then accumulate into the parameter fields of LstmGradient and send a combined state gradient to the previous hidden state. LstmStep is the forward cache: it stores the input, previous states, gate outputs, new states, and prediction for one time index.

The forget-bias initialization is one, making its initial sigmoid greater than one half. This is a practical starting choice, not a guarantee of long memory. Numerical tests perturb the LSTM candidate input weight and the RNN recurrent weight, comparing central differences against the complete analytic BPTT gradients.

4. Make time the evaluation boundary

A temporal split fits earlier observations and evaluates later ones. The first 81 values provide 80 training targets. Validation starts with value 80 as context and predicts values 81 through 120, giving 40 later targets. The value at the boundary is input context, never a training target from the future.

During training, each next-step prediction receives the true previous sequence value. Validation explicitly uses the same teacher-forced input rule: each model resets hidden state to zero and reads true observed inputs in order, so prediction error does not feed back as the next input. Free-running inference instead feeds each generated output back as the next input and answers a harder, different question.

A persistence baseline predicts xt+1 = xt. Slow signals make this deceptively strong. Always compare a learned forecaster with such a task-relevant baseline before celebrating lower loss than random initialization.

cargo test --manifest-path projects/ch23/Cargo.toml
cargo run --release --manifest-path projects/ch23/Cargo.toml

The complete reference measured:

persistence validation one-step MSE 0.01390

LSTM validation one-step MSE 0.39095 -> 0.01779

Both learned models substantially improve from initialization. The RNN slightly beats persistence on this run; the LSTM does not. More gates do not guarantee a better result on one simple signal and fixed settings. We report the unfavorable comparison because the baseline defines the actual bar. One temporal origin and a deterministic series do not establish forecasting performance or uncertainty.

Debugging · Validation looks impossibly good

A learner randomly shuffles overlapping windows from the whole series, then sends 20% to validation.

Answer

Near-identical windows and future regimes can cross the split. Define a chronological boundary on the original series before making windows. Fit scaling only on the training prefix. Use earlier context for the first later target, but never include a later target in fitting.

Independent variation · Evaluate a free-running horizon

Starting at the temporal boundary, generate ten values by feeding each generated output back as the next input. Compare horizon-specific squared error with persistence.

Worked protocol

Train exactly as before with true previous values. At inference start, reset hidden state and supply only the final observed training value. Record errors separately for horizons one through ten because accumulation changes difficulty. The existing explicitly teacher-forced numbers cannot be relabeled as free-running performance; report both.

All cell and output weights are reused. Later states depend on earlier states, so their gradient contribution must arrive first. Cell memory combines retained old memory and a gated candidate. Teacher forcing supplies the true previous sequence value during training or explicitly teacher-forced evaluation; free-running inference supplies a generated output instead. Training improvement is relative to initialization; a simple baseline may already match the signal's strongest short-term structure.

This project uses one scalar state, full-prefix gradients, one chronological split, and one-step observed inputs. In Chapter 24, learned vectors will represent discrete users and items, and evaluation will shift from numeric forecast error to the order of recommended candidates.

The project uses the modern LSTM variant with a forget gate. The 1997 paper introduced LSTM; Gers, Schmidhuber, and Cummins subsequently introduced the adaptive forget mechanism in Learning to Forget: Continual Prediction with LSTM (2000). This distinction matters when tracing the displayed equations to their historical sources. The closed-fixture sequence routines assert that each sequence has at least two finite observations; training settings must be positive and finite.
