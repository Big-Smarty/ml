Which number tilts the line, and which shifts it?

Take raw input 2, multiply it by 0.5, then add 1. The result is 2. The multiplier controls how strongly the raw input affects the prediction; the added number accounts for an offset. We call them the weight w and bias b. For any input x, this rule becomes:

y^=wx+b

The hat on y^ means predicted y. All four quantities are single numbers, or scalars. The same two parameters w and b serve every row. This straight-line rule is the course’s simplest neuron: a mathematical building block, not a biological simulation.

At w=1.5 and b=0.5, input 2 produces 3.5, while input −2 produces −2.5. Adding 0.5 to the bias adds 0.5 to both predictions. Adding 0.5 to the weight adds 1 to the first and subtracts 1 from the second. A weight changes sensitivity; a bias changes the common offset.

In the source, Model is a type alias for [f64; 2]: an array storing [weight,bias]. The alias names the pair without introducing new behavior.

pub fn predict(model: Model, x: f64) -> f64 {
    model[0] * x + model[1]
}

How can we compare two imperfect rules?

For input 2 and target 5, the zero model's error is 0−5=−5. Squaring gives 25. We square before adding because signed errors can cancel: errors of +3 and −3 have mean zero but neither prediction is right. The mean squared error, MSE, averages those squared errors over the dataset.

The sum is 45; dividing by five gives 9. For the baseline's w=1.5, b=0.5, the errors are 0.5,0,−0.5,−1,−1.5. Their squares sum to 3.75, giving 0.75. A lower number means a better fit under this chosen score, or loss.

L(w,b)=1N∑i(wxi+b−yi)2

L names the loss function. N is the number of rows, and ∑i means add the expression once for each row i. Inputs and targets stay fixed while w and b change. MSE has squared target units; an error twice as large contributes four times as much. One bad target can therefore pull the fitted line strongly.

Can two nearby guesses reveal a direction?

Recall why a fixed grid could miss the changed line. We now ask a smaller question: holding the bias still, does a slightly larger weight improve the loss? At w=0, b=0, try w=+0.01 and w=−0.01. Their losses are 8.9202 and 9.0802. The change is −0.16 across a weight interval of 0.02, so the slope is −8. Increasing the weight lowers loss locally.

gw≈L(w+h,b)−L(w−h,b)2h

h is a small positive probe distance, not the learning rate. The lab uses h=0.00001 and f64. Repeat with b+h and b−h while w stays fixed to estimate gb. The pair of slopes is the gradient. At the starting model it is approximately [−8,−2]. A positive component asks us to decrease its parameter; a negative component asks us to increase it.

Four loss evaluations estimate two slopes. Each evaluation runs the same prediction-and-error calculation over every example. Tiny h does not mean perfect accuracy: subtracting almost equal floating-point values eventually loses precision. We use a sensible fixed value here and study the tradeoff in Chapter 02.

For these symmetric inputs, L=2(w−2)2+(b−1)2. At (3,2), increasing either parameter raises loss; both slopes are positive, approximately 4 and 2. This shortcut describes this dataset only. The trainer must compute from its data argument so a different line works too.

Can your program turn slopes into learning?

A gradient gives a direction; the learning rate η chooses how far to move. Starting from [0,0], subtract 0.1 times [−8,−2]: the new model is [0.8,0.2]. Its MSE is 3.52. This single step has made a substantial improvement without being told the correct parameters.

wnew=w−ηgw;bnew=b−ηgb

What did the successful run establish?

With 100 moderate updates, parameters approach [2,1]. Inference at x=0.5 computes 2×0.5+1=2. No targets or gradient are needed, and model parameters stay fixed. Training changes parameters using examples; inference uses the resulting rule. The predicted value at 3 is 7, although 3 was outside the training range.

Within-range prediction is interpolation; outside-range prediction is extrapolation. This exact line makes both succeed. A sensor that saturates above 2 would violate the model assumption outside the observed range. A low training loss would not reveal that failure. Transfer and limitation

The alternate rule is −0.5x+3, so its unseen prediction at 1.5 is 2.25. Both uncorrupted datasets fit exactly; the original-line outlier variant makes a perfect straight line impossible. MSE training compromises across all rows and gives the corrupted row substantial influence. More training cannot turn an inconsistent straight-line dataset into an exact straight line.
