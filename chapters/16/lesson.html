How far is a correct point from the boundary?

Two lines can classify the same points correctly while leaving very different room for measurement noise. A margin-based model asks for a separating corridor as well as correct signs. The maintenance table's overlapping labels mean that some violations will remain.

Retrieve the earlier linear score: multiply matching weights and features, sum, and add bias. For weights [.5,1], bias −.5 and input [2,1], the score is .5×2+1×1−.5=1.5. A nonnegative score predicts the positive class; the score itself is not a probability.

Encode the observed label as y∈{−1,+1}. The signed margin is y×score. The example with positive label has margin 1.5. Input [0,1] gives score .5; a negative label gives margin −.5, exposing a mistake. A correctly classified point with margin .1 has the right sign but sits inside the desired corridor.

Multiplying all weights and bias by ten changes neither decision nor boundary, yet multiplies every functional margin by ten. Geometric distance to the plane is |score|‖weights‖, where the norm is the square root of the sum of squared weights. Fixing a score convention and penalizing weight magnitude prevents arbitrary score inflation from masquerading as a wider corridor.

What does the corridor cost?

A hinge loss is max⁢(0,1−margin). Margins −.5,.5,1.5 incur losses 1.5,.5,0. Correct signs do not eliminate hinge loss until the functional margin reaches 1. Exactly at 1, the function has a corner; the implementation chooses the valid zero hinge subgradient.

Suppose weights [1,−2], λ=.1 and three margins [1.4,.6,−.2]. Mean hinge loss is (0+.4+1.2)3=.5333. The squared weight norm is 5, so the penalty (λ2)×5=.25. The complete objective is about .7833.

Write that objective as:

J=λ2‖w‖2+1n∑imax⁢(0,1−yi⁢(w⋅xi+b))

n is the training-row count, w is the feature-weight vector, b is bias and λ is regularization strength. This objective averages data loss; an alternative text may use C times a sum instead. Do not copy numeric C and λ settings between conventions without translating their scale.

Implement the soft-margin updates

Differentiate the active linear hinge: its weight contribution is −y⁢x and its bias contribution is −y. The squared weight penalty contributes λ⁢w. A stochastic subgradient step therefore shrinks every weight by 1−η⁢λ and, when the old margin is below 1, adds η⁢y⁢x. The bias receives η⁢y only for an active hinge and has no norm penalty.

Compute the old margin before changing any parameter. Then update all weights from that same state. If the margin is already at least 1, only weight shrinkage remains. A later pass can bring the point inside the corridor again. This behavior is expected under the averaged hinge-plus-penalty objective.

fn score(&self, features: [f64; 2]) -> f64 {
    self.weights[0] * features[0] + self.weights[1] * features[1] + self.bias
}

fn predict(&self, features: [f64; 2]) -> f64 {
    if self.score(features) >= 0.0 {
        1.0
    } else {
        -1.0
    }
}

Can similarity make a boundary curve?

Recall XOR's diagonal corners. A single line cannot make the lower-left and upper-right positive while the other corners are negative. A kernel computes a dot-product-like similarity in an implicit transformed space, allowing a linear rule there to produce a nonlinear boundary in the original coordinates.

The radial-basis-function kernel is exp(−γ×squared_distance). With γ=.5, points [0,0] and [1,0] have similarity exp⁢(−.5)≈.6065. Moving the second point to [2,0] makes squared distance 4 and similarity exp⁢(−2)≈.1353. Larger γ localizes influence more sharply.

A kernel score sums αi×yi×K⁢(trainingi,query). Each α is a learned coefficient, y is a signed label and K is the similarity. The new lab teaches a kernel perceptron: visit training rows and increment αi when yi×score is nonpositive. It does not solve the maximum-margin kernel-SVM dual. The linear branch supplies the SVM objective; the nonlinear branch isolates kernel similarity.

Valid kernels produce symmetric positive-semidefinite Gram matrices, whose entries compare pairs of training points. The ordinary dot product is a linear kernel; (1+a⋅b)2 is a polynomial example. The RBF corresponds to an implicit infinite-dimensional feature space. An arbitrary “similarity” is not automatically a valid kernel.

Use the shared geometry illustration in RBF view to check the numerical decay. Its fixed corners show a calculation, not fitted maintenance performance.
