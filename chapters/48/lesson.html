How can one input choose which parameters run?

A router scores three experts [1,0,−1]. Their probabilities are approximately [0.665,0.245,0.090]. It selects expert zero; if that expert returns 3, the layer returns 0.665×3≈1.995. Only one expert executes, although all router scores were calculated.

This is a mixture of experts: several parameterized functions and a learned rule for choosing among them. Here each input x has two features, each expert produces one scalar, and router and expert weight arrays both have shape [3,2]. The router row for expert i computes zᵢ=Wᵣ,ᵢ·x. An expert additionally has its own scalar bias. The output is a prediction for regression, not a probability just because it uses a probability as a gate.

Softmax subtracts the maximum score before exponentiating: exp(0), exp(−1), exp(−2) sum to about 1.5032. Dividing by that sum gives the probabilities above. Adding 1,000 to every score leaves them unchanged. Hard top-1 selection retains the largest probability; this small layer resolves exact ties by the first expert index.

Why can falling loss hide a frozen router?

Recall the chain rule: multiply the local changes along every path from a parameter to loss. Let p be the selected full-softmax probability, u the selected expert output, and y the target. Prediction is pu. This chapter uses half squared error ½(pu−y)²; its derivative with respect to prediction is error e=pu−y. Ordinary MSE has an extra factor of two.

The expert receives derivative ep; the gate receives eu. If m is the chosen expert, softmax gives ∂L/∂zⱼ = eu pₘ (I[j=m]−pⱼ). I is one when j=m and zero otherwise. For p≈[0.665,0.245,0.090], u=3, y=1, the error is 0.995. The common factor eupₘ is about 1.985. The three logit gradients are approximately [0.665,−0.486,−0.179], summing to zero. Multiplying each logit gradient by the two input features gives that router row’s weight gradients.

Now normalize only the selected probability: p/p=1. Prediction becomes u, independent of router scores as long as the winning index stays fixed. Expert weights can still learn, so a falling loss does not reveal the missing router path. Backpropagation differentiates the retained probability, not the discrete argmax. Finite-difference checks must stay away from ties where the selected branch changes.

A top-2 scheme can normalize two selected gates because their relative values still change. That reasoning does not transfer to a single selected gate. Implement the top-1 contract first and state any different routing rule explicitly.

Which token is dropped when one expert fills?

For T attempted tokens, E experts, and positive capacity factor c, this lab sets C=max(1,ceil((T/E)c)). Tokens here are two-feature regression examples, not text IDs. With T=12, E=3, c=1.25, capacity is five. Attempted loads [8,3,1] become admitted loads [5,3,1], with three drops. Raising capacity provides more room; it does not repair the concentration of routes.

Admission follows a deterministic order. The training fixture rotates its first example each epoch so the same tail is not always dropped. Count attempted assignments before deciding admission. Count accepted assignments separately. A dropped example contributes no expert task gradient in this standalone scalar layer, although it still participates in the balancing calculation. The later decoder adds a residual path, so a dropped expert contribution will not erase a token’s representation.

Predict the capacity-three result for attempted loads [2,6,8]: admission [2,3,3] and eight drops. Do not change the task denominator to eight accepted examples. The training objective here is the accepted half-squared-error sum divided by all sixteen attempts, plus auxiliary loss. Overflow therefore changes the magnitude of the task gradient. Reporting only a smaller capped training objective could mistake dropping for learning.

What does a balancing loss actually encourage?

Let fᵢ be expert i’s attempted hard-assignment count divided by T. Let Pᵢ be its full-softmax probabilities summed across every token and divided by T. Switch-style balancing adds Lbalance=αEΣᵢfᵢPᵢ. α is an explicit coefficient, 0.02 in this scalar fixture. Both vectors describe all attempts, including drops.

For three completely collapsed experts, f=P=[1,0,0], so the unweighted value is three. If both are uniform, it is one. One is a useful balanced reference, not a global-minimum guarantee: with two experts, f=[0.75,0.25] and P=[0.385,0.615] give 2(0.28875+0.15375)=0.885. Hard frequencies and mean probabilities need not match. Nor does balanced traffic prove that experts learned meaningful specialties.

During a local derivative, f is held fixed; P remains differentiable. Every token receives probability derivative αE fᵢ/T for expert i. Add this to the selected task probability derivative. For a probability-gradient vector g, the full softmax backward is dzⱼ=pⱼ(gⱼ−Σᵢgᵢpᵢ). That one formula handles task and auxiliary contributions without separate special-case derivatives.
