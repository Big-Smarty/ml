How can four pixels be compared with a word?

An image is four pixel intensities; a caption is one of three shape words. Their raw coordinates do not mean the same thing, so a pixel-word dot product has no useful interpretation. Two encoders map them into a shared two-coordinate space where a comparison can be learned.

The image tower is a matrix with shape [2,4], and the text tower has shape [2,3] applied to a three-coordinate one-hot vocabulary vector. A batch of N pairs produces image embeddings [N,2] and text embeddings [N,2]. The towers share the output dimension and training objective, not their input format or parameter values. This tiny vocabulary is not an open-language encoder.

Normalize each embedding u by its Euclidean norm ∑juj2. For [3,4], the result is [0.6,0.8]. Its similarity to normalized [4,3]=[0.8,0.6] is 0.48+0.48=0.96. The dot product of unit vectors is cosine similarity: magnitude no longer wins by itself.

A zero vector has no direction and cannot be normalized. The supplied implementation rejects zero and nonfinite vectors. Adding an epsilon and silently accepting a zero embedding would define a different convention, which both training and evaluation would need to share.

Run just lab 52. The baseline trains paired embeddings toward each other using squared distance. That is a useful alignment baseline, but contains no mismatched-pair penalty. All embeddings could point in one direction while every pair agrees.

Why does the correct pair need competitors?

Construct the N×N matrix S with Sij=imagei·textj. Diagonal entries are known training pairs. Divide similarities by a positive temperature τ to obtain logits. For two perfectly orthogonal paired directions and τ=1, the matrix is [1001]. Each row assigns its diagonal probability e(e+1)≈0.7311, so row cross-entropy is about 0.3133.

Image-to-text cross-entropy asks each row to choose its diagonal column. Text-to-image asks each column to choose its diagonal row. Symmetric InfoNCE averages both directional losses:

L=∑iCE⁡(Si,:τ,i)+∑jCE⁡(S:,jτ,j)2N.

Rows and columns need not have identical normalizers. A single softmax over all N2 cells is the wrong objective.

Calculate cross-entropy from logits using a stable log-sum-exp: subtract the largest logit before exponentiating, then add it back to the logarithm. Subtract the diagonal logit to get the row or column loss. This avoids log of a probability that underflowed to zero.

For the same two-pair example at τ=0.5, diagonal logits become two and the loss falls to log⁡(1+exp⁡(−2))≈0.1269. The embeddings did not change. Temperature changes probability sharpness and gradient scale, so a lower scalar loss after changing τ alone is not improved retrieval geometry.

The lab estimates gradients of fourteen parameters by finite differences. Both encoders participate in each objective evaluation, including normalization. Differentiating only the raw matrix product while treating the norm as fixed would optimize a different function.

What does Recall@1 count?

For each image query, rank the candidate captions by raw cosine similarity. Recall@1 here is the fraction whose highest-scoring candidate is the designated paired caption. Three correct top choices out of three gives 100%. This is a classification-like retrieval metric over a fixed tiny candidate set, not a calibrated probability of semantic correctness.

The goal harness trains both towers and checks that both parameter matrices changed. It reports training-pair retrieval and perturbed versions of the same three underlying image patterns. A frozen image tower might sometimes succeed, but that would not demonstrate the requested joint training. Changing the target can require both representations to move.

Perturbations share the training concepts and nearly the same construction. They test a limited local robustness claim. They are not independent evidence of open-vocabulary recognition, new shape generalization, or reliable image search. A larger evaluation should separate concepts and sources, avoid near duplicates, and report both retrieval directions.

The candidate set matters. Three obvious options can make Recall@1 look excellent while a larger set of near matches reveals ambiguity. Keep the query set fixed when changing candidates so that a metric change has an interpretable cause. A raw similarity of 0.9 has no universal threshold meaning across datasets.

When is a mismatched pair actually a valid answer?

In-batch negatives assume that the other captions are unsuitable for the current image. If two rows both contain a square image and a caption saying “square,” their off-diagonal pair may be semantically correct. Single-diagonal cross-entropy nevertheless penalizes it. That is a false negative created by the training labels.

Consider two identical normalized image embeddings and two identical caption embeddings. Every similarity is 1. Each direction’s target probability is 12 and loss ln⁡2. No parameter update can distinguish the identical inputs while preserving deterministic encoders. Trying to force a diagonal-only objective to 0 would ask for information the inputs do not contain.

Possible larger-system responses include deduplicating near-identical pairs or defining multiple positives. These change data or the objective and need their own evaluation. The present lab retains one designated pair per row so that the arithmetic remains inspectable; document the assumption rather than claiming the model has solved ambiguity.

Training data also determines which visual and linguistic associations are rewarded. A tiny successful demonstration cannot establish absence of social bias or safe deployment. Chapter 54 supplies quantitative audit tools; here the concrete responsibility is to state which queries, candidates, labels, and perturbations the retrieval result actually covers.
