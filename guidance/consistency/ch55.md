# Chapter 55 consistency revision

## Interface mapping

- The scratch oracle keeps Chapter 9's `Dense::forward` role, now specialized to `forward(&self, input: [f32; 2]) -> [f32; 2]`, and row-major `[out_features,in_features]` storage, now consistently named `weights: [[f32; 2]; 2]`. `bias: [f32; 2]` is unchanged.
- `loss_and_grad(&self, input, target) -> (f32, Dense)` is now `loss_and_gradient(&self, input: [f32; 2], target: [f32; 2]) -> (f32, Gradient)`. The distinct `Gradient { weights, bias }` prevents derivative data from masquerading as a trained model. The arithmetic, argument order, fixture, and return loss are unchanged.
- `step(&mut self, grad: &Dense, rate: f32) -> Result<(), &'static str>` is now `apply_sgd(&mut self, gradient: &Gradient, learning_rate: f32) -> Result<(), &'static str>`, matching Chapter 36's split between computing a precomputed gradient and applying one in-place optimizer update. `RATE` is now `LEARNING_RATE`.
- The starter now uses the same `Dense::fixture().forward(input)` organization and fixture as the reference. Its standalone loss primitive is `mean_squared_error(output, target)`, with predictions before targets. The learner still supplies only the local weight derivative.
- The optional Burn program keeps its native Burn 0.21 tensor operations and explicitly maps scratch `[out,in]` weights to matmul `[in,out]` weights. Local matrix names are plural, and the artifact parser's `p` scratch array is now `parameters`.

No external crate calls the private Chapter 55 scratch methods. The `export NEW_ARTIFACT_PATH` and `import SCRATCH_ARTIFACT` CLI forms, error strings, tolerances, fixture values, Burn recorder behavior, and update order remain unchanged. The course format remains exactly `CH55DENSE01` followed by six little-endian f32 values: four scratch-row-order weights and two biases. `save` retains exclusive creation, and both loaders retain their 36-byte read cap for rejecting oversized artifacts.

## Shapes and reduction contract

- Scratch input and target are `[2]`; output is `[2]`. Scratch `Dense.weights` and `Gradient.weights` are `[out_features=2,in_features=2]`, and both bias arrays are `[out_features=2]`.
- Burn input and target are `[batch=1,features=2]`. Burn matmul weights are the explicit transpose `[in_features=2,out_features=2]`; the bias `[2]` becomes `[1,2]` for batch broadcasting.
- The scalar objective is ordinary MSE over both output coordinates: `sum((output-target)^2) / 2`, with no half factor. More generally it averages over `B*O` values. For this `B=1,O=2` fixture, `dL/doutput = 2*error/2 = error`, so each weight derivative is `error[o] * input[i]`.
- `apply_sgd` validates the learning rate, every parameter, every derivative, and every proposed updated value before mutating weights or bias. It then performs one simultaneous in-place update and returns `Ok(())`.
- Numerical parity requires finite, equal-length inputs and uses `abs(a-b) <= 1e-6 + 1e-5*max(abs(a),abs(b))`. Serialization round trip remains exact because it restores the same f32 bytes.
