# Chapter 06 consistency record

## Interface mapping

- `Model { weight, bias }` -> `Neuron { weight, bias }`.
- `predict(self, x)` -> `predict(&self, input)`.
- `mse(self, data)` -> `loss(&self, data)`.
- `minibatch_step(self, batch, rate, l2)` -> `step(self, batch, learning_rate, l2)`.
- Free `train(rate, batch_size, l2, epochs)`, which captured `TRAIN` and `VALIDATION` -> `Neuron::train(self, train_data, validation_data, epochs, batch_size, learning_rate, l2)`.
- Exercise `l2_gradient(data_gradient, weight, lambda)` -> `regularized_weight_gradient(data_gradient, weight, l2)`, matching the starter and the named weight component of `Neuron::step`.

`Neuron`, `Gradient`, `predict`, `loss`, and the consuming `step`/`train` update style now continue the Chapter 2 scalar interface. Chapter 6 changes the `step` data argument from a whole dataset to one explicit minibatch and adds `l2`. Its `train` method adds explicit validation data, epoch count, and batch size. The lesson explains each addition before use.

## Loss, data, and reduction conventions

- Every example remains `(input, target)` with scalar `f64` input and output.
- `TRAIN` still has 12 fixed noisy-regression examples and `VALIDATION` still has 6; their values are unchanged.
- `Neuron::loss(data)` is ordinary mean squared error over every supplied example, with no factor of one half and no regularization term.
- `Neuron::gradient(data)` differentiates that same mean loss. A shorter final minibatch divides by its own length.
- One `step` minimizes the minibatch data loss plus `l2 * weight^2`; only the weight receives the `2 * l2 * weight` penalty derivative.
- Training and validation curves call the unregularized `loss` on their full explicit slices at each epoch boundary. With 12 examples and batch size 4, one epoch contains 3 optimizer steps; 80 epochs contain 240 steps.
