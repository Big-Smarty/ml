# Chapter 15 consistency revision

## Continuity and interface mapping

The lesson now opens with the required continuity section linking Chapter 14 and `/conventions.html`. Chapter 14's finalized fixed-row conventions carry forward directly:

- `Row.features: [f64; 2]` contains the two numeric model inputs.
- `Row.label: usize` is the observed binary class ID used by the classification tree and forest.
- `Row.target: f64` is the separate numerical regression target used by boosting.
- `Tree::predict(features)` returns one leaf label. `forest_predict(trees, features)` aggregates those labels by majority vote.
- `Stump::predict(features)` returns one numerical residual correction. `Boost::predict(features)` returns the base regression prediction plus every `learning_rate`-scaled correction.

Classical estimator construction now uses `fit_tree`, `fit_random_tree`, `fit_forest`, `fit_stump`, and `Boost::fit`. These operations estimate split structure or leaf values from training rows. Chapter 15 does not expose `train`, which remains the course name for repeated optimizer updates. The former `Boost::fit(..., rate)` argument and `Boost.rate` field are now `learning_rate`. Mathematical η remains in the equations and is explicitly identified as the learning rate.

The standalone exercise and starter use the count-based primitive `gini_impurity(positive, total)`. The reference's `gini_impurity(rows)` calculates the same quantity from stored labels. The starter's guided `weighted_impurity(left, right)` receives each child as `(positive_labels, row_count)`, matching its hints, arithmetic, and failing test.

The continuity section also maps the boosting sign convention before residuals are introduced: the early-course signed `error = prediction - target`, while this chapter's correction target is `residual = target - prediction = -error`. For training-row MSE, the derivative is `2 * error / N`, so residuals point in the negative-gradient direction up to the fixed positive factor `2/N`.

## Split criteria, loss, shapes, and reductions

- Every row has shape `[2]`: two `f64` features, one discrete classification label, and one `f64` regression target.
- `gini_impurity` measures class mixing within one node as `2p(1-p)`.
- `weighted_impurity` combines child Gini values using child row counts divided by parent row count. Both deterministic and randomized classification-tree fitters use this named criterion.
- `fit_stump` compares candidates with `residual_sse`, the sum over rows of squared differences between current residuals and the candidate stump's residual predictions.
- The boosting model's conceptual optimized loss is regression MSE, averaged over training rows. Residual SSE chooses the same candidate split because every candidate has the same positive row-count denominator.
- A forest fits independent bootstrap trees and predicts by majority vote. Regression-forest averaging is explained as a different aggregation and is not claimed as implemented.
