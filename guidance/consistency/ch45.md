## Returns, shapes, and reductions

- The bandit performs one environment interaction per step and returns three scalar action-value estimates `[3]`. Only the selected arm receives an incremental sample-mean update; there is no supervised target or loss reduction.
- The chain Q table is row-major by construction as `[[f64; 2]; 5]`: rows are states and columns are `Left` and `Right`. `environment_step` returns one `(next_state, reward, done)` transition. `q_update` changes one visited cell and omits discounted continuation when `done` is true.
- The lesson and `q-value` glossary now give the canonical definition: expected discounted return beginning with the immediate reward after a specified state and action, then following a policy. Q-learning's behavior policy explores while its bootstrap uses a greedy target policy.
- REINFORCE maps two unrestricted policy logits `[2]` through stable softmax to two normalized action probabilities `[2]`. These are distinct from Q-values. Each episode has one action, so the scalar reward is the complete return; one sampled log-probability gradient then updates both logits. There is no batch average.
- The Q-learning learning rate `0.2`, discount factor `0.95`, REINFORCE learning rate `0.08`, baseline smoothing `0.05`, episode/step counts, fixtures, seeds, and update ordering are unchanged.
