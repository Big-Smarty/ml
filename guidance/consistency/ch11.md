# Chapter 11 consistency review

## Interface mapping

- Chapter 10 `Dataset { images, labels }` and `image(n)` now continue unchanged in the Chapter 11 reference and starter; the former `x`, `y`, and `row` identifiers were removed.
- `Mlp::loss_grad(data, start, end)` became `Mlp::loss_and_gradient(data, start, end)` in every owned caller. Its return remains `(mean_loss, mean_packed_gradient)`.
- The packed model field `p` became `parameters`, and `parts()` became `parameter_offsets()`. The returned starts map to W1 `[hidden,input]`, b1 `[hidden]`, W2 `[10,hidden]`, and b2 `[10]`, in that byte-preserving order.
- `probs` became `probabilities`; `cross_entropy` became `cross_entropy_from_logits(logits, target)`. A stored `label` is a discrete class ID; `target` is the generic class argument to the loss.
- `Optimizer::update(parameters, gradient)` became `Optimizer::step(parameters, gradient)`. Its `rate` field became `learning_rate`, and its `step` field became `step_count`, the number of complete parameter-vector updates used as Adam's bias-correction exponent.
- The scalar Rustlings `momentum(velocity, gradient, beta)` operation maps to the reference momentum branch for one parameter. The starter's `momentum_step(parameter, velocity, gradient, learning_rate, beta)` maps to one iteration inside `Optimizer::step`.

These Rust APIs are chapter-local; no external repository callers or path dependencies were found.

## Shapes and reductions

Images are contiguous row-major `[examples,input]`; `Dataset::image(n)` returns `[input]`. Dense weights are packed row-major as `[out_features,in_features]`. `forward` returns hidden activations `[hidden]` as the backward cache and logits `[10]`; prediction is the greatest-logit class computed during metrics. `loss_and_gradient` applies maximum-shifted log-sum-exp cross-entropy and divides both accumulated loss and every parameter derivative by `end - start`. Metrics average loss and accuracy over the full supplied dataset.
