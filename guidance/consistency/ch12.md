# Chapter 12 consistency revision

## Continuity and interface mapping

Chapter 12 now explicitly consumes frozen model outputs rather than training state. Its early `continuity` section links Chapter 11 and `/conventions.html`, then maps one selected Chapter 11 softmax class to the binary evaluation row used here:

- `Prediction.probability` is the frozen model's probability for a positive class chosen before test evaluation.
- `Prediction.label` is `1` when the observed class is that positive class and `0` otherwise.
- Chapter 11's training cross-entropy is not copied into Chapter 12. Accuracy, Brier score, bootstrap estimates, and calibration summaries are recomputed from held-out probability/outcome rows.
- The bundled fixture remains course-authored and is not presented as output from a trained checkpoint. No model or checkpoint dependency was invented.

The reference and starter already accepted `brier(data: &[Prediction])`. The Rustlings exercise and solution now use the same `Prediction { probability, label }` row and argument order instead of separate `probabilities` and `labels` slices. The small closed-fixture exercise returns `f64` and asserts nonempty input; the reference retains its `Result` boundary for malformed evaluation data.

The reference now routes `accuracy`, `brier`, and `calibration_bins` through one `validate_predictions` helper. This removes the misleading implementation detail in which Brier validation called `accuracy`, without changing accepted inputs or computed statistics. Printed calibration columns are now named `mean probability` and `positive frequency`; the interval is identified as a bootstrap percentile confidence interval.

## Shapes, reductions, and statistical terms

- One `Prediction` contains one `f64` positive-class probability and one binary observed label encoded as `u8`.
- `accuracy` thresholds each probability at 0.5 and divides correct decisions by the number of rows.
- `brier` sums `(probability - label)^2` and divides by the number of rows. It is a held-out evaluation metric, not the classifier's training objective.
- `bootstrap_accuracy` resamples complete `Prediction` rows with replacement, recomputes accuracy, sorts the replicate statistics, and reports empirical 2.5th and 97.5th percentile endpoints.
- The lesson describes a nominal 95% confidence procedure through repeated-sample coverage. It does not assign 95% probability to a fixed population quantity or claim coverage for the eight-row fixture.
- `calibration_bins` reports each nonempty bin's row count, mean predicted positive-class probability, and observed positive-outcome frequency. The lesson distinguishes this descriptive estimate from fitted recalibration and from discrimination.
- The Brier glossary definition now says “predicted probabilities and binary outcomes,” and states the row denominator. Its explanation retains the calibration, resolution, and outcome-uncertainty limitation.

The lesson contains three checked `data-source` excerpts: the reference `Prediction`, the reference `brier`, and the Rustlings solution `brier`.
