## Shapes, arithmetic, and tolerance

`left`, `right`, and `output` are contiguous `[N]` `f32` vectors. Addition is elementwise and performs no reduction. `dispatch_count` uses ceiling division, and the shader checks each global ID against `dispatch_params.element_count`, so a partial final 64-invocation workgroup cannot index the tail out of bounds.

The CPU oracle now calls the named `add_scalar` primitive. GPU comparisons use `|actual - expected| <= 1e-6 + 1e-6 * |expected|`. The default executable returns an error when the GPU result violates this rule; the ordinary CPU test checks both accepted and rejected differences.
