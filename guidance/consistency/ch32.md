## Shapes, numerics, and preserved behavior

`affine_relu_scalar` and every GPU plan implement `output[i] = max(1.5 * input[i] + 0.25, 0)` for contiguous `[N] -> [N]` f32 data. There is no reduction or learned parameter. The deterministic length, values, warmup count, sample count, plan order, feature requests, input validation, device-limit checks, buffers, dispatches, timestamp conversion, f16 threshold, f32 tolerance `1e-5`, f16 tolerance `0.01`, CLI commands, hardware error, dependencies, and cited RX 6950 XT measurements are unchanged.

The CPU wall clock still starts after input/output/query resource allocation and before bind-group creation and encoding. It stops after output mapping, which supplies explicit completion through the mapping callback, `device.poll(PollType::wait_indefinitely())`, and the standard-library channel. Timestamp staging is mapped and decoded afterward. Separate-plan device time remains the sum of its two pass intervals, not an end-to-end duration.
