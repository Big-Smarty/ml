# Chapter 01 consistency record

## Interface and terminology

Chapter 01 now establishes the shared Chapter 01/02 scalar interface:

```rust
struct Neuron { weight: f64, bias: f64 }
struct Gradient { weight: f64, bias: f64 }
fn predict(&self, input: f64) -> f64;
fn loss(&self, data: &[(f64, f64)]) -> Result<f64, &'static str>;
fn numerical_gradient(&self, data: &[(f64, f64)]) -> Result<Gradient, &'static str>;
fn step(self, data: &[(f64, f64)], learning_rate: f64) -> Result<Self, &'static str>;
fn train(self, data: &[(f64, f64)], steps: usize, learning_rate: f64) -> Result<Self, &'static str>;
```

The reference, starter, lesson, and Rustlings pair use `Neuron::predict`. The reference and starter use the complete method set. `train` receives its dataset explicitly, and `step` returns the updated model. Chapter 02 can retain `predict`, `loss`, `numerical_gradient`, `step`, and `train` unchanged while adding analytical `gradient` and changing only the gradient used by `step`.

Old reference mapping:

- by-value `predict(self, input)` -> borrowing `predict(&self, input)`
- by-value `loss(self, data)` -> borrowing `loss(&self, data)`
- gradient arithmetic embedded in `step` -> `numerical_gradient(&self, data) -> Result<Gradient, _>`
- free `train(steps, rate)` with hidden `TRAIN` -> `Neuron::train(self, data, steps, learning_rate)`

Learner starter mapping:

- completed free `predict(weight, bias, input)` -> completed `Neuron::predict(&self, input)`
- `mse(w, b, input, expected)` -> `Neuron::loss(&self, data)`
- `gradient_weight` and `gradient_bias` -> named fields returned by `Neuron::numerical_gradient`
- `new_w` and `new_b` -> one simultaneous `Neuron::step`
- free `train(samples, iterations, h, eta)` -> `Neuron::train(data, steps, learning_rate)`; the learner's 1,000-step call remains in `main`
- learner-selected finite-difference value `0.00001` -> the course-wide fixed `H = 1e-5`

## Loss, shapes, and numerical behavior

`TRAIN` remains the five `(input, target)` scalar pairs for `target = 2 * input + 1`. `predict` maps one scalar `f64` to one scalar `f64`. `loss` is ordinary mean squared error over every supplied example, with no factor of one half. Empty data, nonfinite model/data values, nonfinite gradients, and nonfinite or nonpositive learning rates return `Err`.

Central differences use `h = 1e-5`. Weight and bias derivatives are measured from the unchanged model. Initial loss remains 9, the initial numerical gradient remains `Gradient { weight: -8, bias: -2 }`, and one update at learning rate 0.1 remains `Neuron { weight: 0.8, bias: 0.2 }` with loss 3.52. An asymmetric fixture `[(1, 0), (2, 0)]` now proves both fields update from the same old model; starting from `(1, 1)`, one 0.1 step yields `(0.2, 0.5)`.
