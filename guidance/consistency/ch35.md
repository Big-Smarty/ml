# Chapter 35 consistency revision

## Interface and terminology mapping

Chapter 35 remains a standalone CPU attention primitive rather than a language-model type. It receives direct contiguous row-major Q, K, and V arrays; it does not receive Chapter 34 token IDs, load a BPE file, look up embeddings, train projections, or predict a token class. The lesson now states that boundary before technical use and links Chapters 34, 33, and 09 plus `/conventions.html`.

All renamed Rust callers are chapter-local. A repository-wide caller search found only the reference binary and tests, the Chapter 35 starter, and the Chapter 35 Rustlings exercise/solution. No other package depends on `projects/ch35`, which remains an independent binary crate.

- `Attention::weights` -> `Attention::probabilities`; the [positions,positions] values are stable row-softmax probabilities over source positions.
- `Backward { dq, dk, dv }` -> `AttentionGradients { query_gradients, key_gradients, value_gradients }`.
- `causal_attention(q, k, v, t, d)` -> `causal_attention(queries, keys, values, positions, width)`; argument order and numerical behavior are unchanged.
- `backward(q, k, v, a, dout, t, d)` -> `backward(queries, keys, values, probabilities, output_gradients, positions, width)`; argument order and numerical behavior are unchanged.
- The test-only free function `loss(...)` -> `attention_probe_objective(...)`. It sums output-times-upstream products only to make a vector-Jacobian product measurable and is not presented as `Model::loss` or next-token cross-entropy.
- The test helper `numeric` -> `central_difference`. The starter now uses `query_position`, `key_position`, `positions`, and `probabilities`; the Rustlings exercise and solution use `query_position` and `key_position`.

## Shapes, reductions, and derivative roles

`queries`, `keys`, `values`, `output`, `query_gradients`, `key_gradients`, `value_gradients`, and `output_gradients` all represent [positions,width]. `Attention::probabilities` represents [positions,positions]. Every array is flat and contiguous in row-major order. A query-key dot product sums over `width`, divides by `sqrt(width)` exactly once, and stable softmax normalizes each permitted source-position row separately. Forbidden future probabilities and their score gradients remain exactly zero. The output weighted sum reduces over permitted source positions and preserves position and feature axes.

`backward` propagates the supplied `output_gradients` and performs no independent mean reduction. Shared query/key/value paths accumulate by addition. Doubling `output_gradients` now has an explicit test that every returned gradient doubles. The finite-difference probe is

`attention_probe_objective = sum over all positions and width of output * output_gradients`.

It has no averaging denominator, token targets, or class logits. The implemented numerical comparison uses epsilon `1e-5` and accepts absolute error below `1e-6 + 1e-4 * abs(numerical)`. In Chapter 33, `probability - one_hot_target` is a derivative with respect to token-class logits. In Chapter 35, `probability_gradients` is the derivative with respect to attention probabilities A before the row-softmax backward rule. The lesson and metadata now distinguish these roles.
