# Chapter 21 consistency review

## Interface mapping

- `ResidualNet::loss_grad(&self, row) -> (f64, Grad)` became `ResidualNet::loss_and_gradient(&self, example) -> (f64, Gradient)` in the reference and every owned caller. It still returns one example's stable cross-entropy and the derivatives of that same scalar.
- `train(&mut self, rows, epochs, rate)` became `train(&mut self, data, epochs, learning_rate)`. Training remains sample-at-a-time SGD with one parameter update per example.
- The duplicated inline logits loss became `cross_entropy_from_logits(logits, target)`, matching Chapters 10, 11, and 20. Stored `Example::label` remains the discrete class ID; `target` is the generic class argument to the loss.
- `NetCache` and `BlockCache` became `ForwardCache` and `ResidualBlockCache`. `block`/`block_backward` became `residual_block_forward`/`residual_block_backward`, separating the layer operations from the whole-model `ResidualNet::forward` method.
- `dout`, `dinput`, `dnorm`, `dkernel`, `dscale`, `dbias`, and `d_first` became role-bearing gradient names. In particular, `first_block_output_gradient` is the 36-value array returned by block-two backward and passed as block one's `output_gradient`.
- The starter and Rustlings `residual(input, branch)` primitive became `residual_add(input, residual_branch)`. Its second argument maps to the already scaled `scale * z` branch value in `ResidualNet::residual_block_forward`; the reference then applies ReLU.

These Rust APIs are chapter-local. No path dependencies or external repository callers were found.

## Shapes and reductions

Each image and block activation has logical shape `[6,6]` and contiguous row-major storage `[36]`. Each 3×3 kernel is stored `[9]`; the dense head is `[2,36]` in class-major row-major order and produces logits `[2]`. `normalize` computes one mean and one population variance over all 36 pixels of one image. `normalize_backward` sums its incoming gradient and gradient-times-normalized-output over the same 36 pixels and divides by 36.

`residual_block_forward` preserves `[36]` through stride-one, padding-one convolution and identity addition. `ResidualNet::forward` returns both block caches and two final logits; the layer output and cache are not task predictions. Metrics derives the predicted class by comparing logits. `loss_and_gradient` has no batch reduction because it consumes one example. Training applies that per-example gradient immediately. Metrics reports mean cross-entropy and correct fraction over all supplied evaluation examples.

In this chapter, residual means the architectural identity-plus-branch sum. It is distinct from the signed regression residual `prediction - target`.
