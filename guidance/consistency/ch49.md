## Numerical and shape contract

`selective_transitions` maps scalar f64 `inputs [positions]` to input-dependent affine `(a,b)` transitions. These fixed coefficients are not trained model weights, and `b` is not a reusable neuron bias. Both state evaluators return `states [positions]` from the same scalar initial state. `recurrent` performs O(N) sequential work. `associative_scan` retains the offset-doubling Hillis-Steele teaching schedule: O(N log N) scalar work and logarithmic dependency depth, executed sequentially here.

Both causal linear-attention paths accept direct f64 `queries` and `keys [positions,2]`, scalar `values [positions]`, and return `output [positions]`. They use the same inclusive prefix, ReLU-plus-one feature map, epsilon, and absolute-plus-relative comparison tolerance. The feature-map kernel differs from the dense row-softmax attention in Chapters 35 and 42 and is not an exact replacement. This chapter performs no model training.
