# Chapter 13 consistency revision

## Continuity and interface mapping

Chapter 13 now links Chapter 12 and `/conventions.html` before technical use. Chapter 12 consumed frozen `Prediction { probability, label }` rows for held-out evaluation; Chapter 13 moves earlier in the pipeline and produces encoded feature vectors from source records. It defines no predictive model, loss, gradient, or evaluation reduction.

The reference and guided starter use the same representation and preprocessing names:

- `Row` became `RawRow` to identify the unencoded source representation.
- `Preprocessor::fit(rows: &[Row])` became `Preprocessor::fit(training_rows: &[RawRow])`. It estimates and stores one median plus the sorted category vocabulary from training rows only.
- `Preprocessor::transform(&self, row: Row)` became `transform(&self, raw_row: RawRow)`. Its local result is `encoded_features`, and the method only reads fitted state.
- `group_split` and `time_split` now accept `RawRow` slices and still return row references with unchanged membership rules.
- The median arithmetic was extracted as `median(&mut [f64]) -> Option<f64>`. This helper has no knowledge of splits and owns no fitted state; `Preprocessor::fit` supplies training values, handles invalid input, and stores its result.
- The old starter exposed only `training_median(values)`. It now carries `RawRow`, `Preprocessor::fit`, and `transform`; its intentional TODO is the median primitive reached through `fit`. Its runnable path applies an already-fitted checkpoint without reaching the TODO.
- The Rustlings `fill_missing(value, training_median)` exercise remains an intentional scalar primitive. The lesson maps its supplied median to state already learned by `Preprocessor::fit` and its one-line operation to the imputation inside `transform`.

`RawRow.label` is a discrete class ID and remains outside `encoded_features`. When a later supervised model pairs that label with the encoded features, the class label fills the model loss's `target` role. Chapter 13 does not pass labels into fitting or transformation.

## Shapes, state, and numerical conventions

- `Preprocessor::fit` consumes a slice of training `RawRow` values and returns `Preprocessor { median, categories }`.
- `transform` returns one contiguous feature vector with length `2 + categories.len()`: imputed numeric value, missing indicator, then one column per fitted category. Stacking vectors gives row-major `[rows, features]` data.
- Unknown categories map to all-zero fitted category columns, so held-out values cannot change feature width or column meaning.
- `median` sorts with `f64::total_cmp`. Odd counts select the middle value; even counts use `f64::midpoint` to preserve the existing finite-extreme behavior without overflow.
- Group and time splits preserve their original fixture membership. The reference CLI output and all numerical values remain unchanged.
- Chapter 05 remains the glossary owner for `data-leakage`; Chapter 13's duplicate metadata definition was removed while its lesson link to the shared term remains.
