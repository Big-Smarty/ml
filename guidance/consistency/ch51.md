# Chapter 51 consistency revision

## Changes and interface mapping

Chapter 51 now carries forward the Chapter 22 model/loss vocabulary, Chapter 38's separation of objective, gradient, and optimizer update, and Chapter 50's caller-supplied training data and settings. The lesson has an early `continuity` section linking those chapters and `/conventions.html`, with the actual scalar parameter shapes, reductions, return types, and update units.

The reference API changes are:

- `finite_gradient(params, loss) -> [f64; N]` became `numerical_gradient(parameters, loss) -> Result<[f64; N], &'static str>`. It still uses central differences with `h = 1e-5`.
- `update(params, gradient, rate)` became `apply_sgd(parameters, gradient, learning_rate) -> Result<(), &'static str>`.
- `Vae { p: [f64; 5] }` became `Vae { parameters: [f64; 5] }`.
- Captured `Vae::loss_with(parameters)` became the borrowing model operation `Vae::loss(&self, data, latent_noise) -> Result<f64, &'static str>`.
- `Vae::train(self, steps) -> Self` became `Vae::train(self, data, latent_noise, steps, learning_rate) -> Result<Self, &'static str>`.
- `Gan::discriminator_loss(discriminator, generator) -> f64` became `Gan::discriminator_loss(discriminator, generator, data, noise) -> Result<f64, &'static str>`.
- `Gan::generator_loss(generator, discriminator) -> f64` became `Gan::generator_loss(generator, discriminator, noise) -> Result<f64, &'static str>`.
- `Gan::train(self, steps) -> Self` became `Gan::train(self, data, noise, rounds, learning_rate) -> Result<Self, &'static str>`. One round means one discriminator optimizer update followed by one generator optimizer update using the new discriminator.
- `Diffusion::loss(self) -> f64` became `Diffusion::loss(&self, data, noise, alpha_bars) -> Result<f64, &'static str>`.
- `Diffusion::train(self, steps) -> Self` became `Diffusion::train(self, data, noise, alpha_bars, steps, learning_rate) -> Result<Self, &'static str>`.
- `Diffusion::sample(self, initial_noise) -> f64` became `Diffusion::sample(&self, initial_noise, alpha_bars) -> Result<f64, &'static str>`; `ddim_step` also receives that schedule explicitly.
- Starter, exercise, solution, and reference now share `reparameterize(mean, log_variance, epsilon) -> f64`. The VAE calls this primitive. The starter's separate `autoencode` remains a labeled deterministic warmup, and both learner TODOs remain intact.

`main` supplies the unchanged six data values, six noise values, four-value diffusion schedule, 500 VAE steps at learning rate 0.03, 1,500 GAN rounds at learning rate 0.02, and 500 diffusion steps at learning rate 0.03. The GAN still updates discriminator before generator in every round.

## Loss and shape conventions

- VAE parameters are a flat `[5]`: encoder weight, encoder bias, log variance, decoder weight, decoder bias. Its beta-VAE objective averages half squared Gaussian reconstruction error plus `0.1 * KL` over the Cartesian product of `N` data and `K` latent-noise values. It is not Chapter 1 ordinary MSE.
- GAN generator and discriminator parameters are flat `[2]` and `[3]`. The discriminator loss requires equal nonempty data/noise lengths and averages a combined real/fake loss over the intentional zipped pairs. The generator loss separately averages its non-saturating loss over supplied noise. The associated loss functions accept both parameter arrays because numerical differentiation substitutes one candidate array while freezing the other.
- The diffusion predictor is a flat `[3]`. Its squared noise-prediction error is averaged over all `N * K * T` data, noise, and timestep combinations. Injected latent epsilon is the denoising target. A reverse sampler transition changes the current sample; `apply_sgd` changes learned parameters.
- Data, noise, parameters, gradients, learning rates, sampler inputs, objective outputs, and schedules are checked for the applicable nonempty, finite, compatible constraints. GAN pairing rejects unequal lengths. A diffusion schedule requires at least two finite, nonincreasing values in `(0, 1]`.
