# Chapter 08 consistency record

## Interface mapping

- Chapter 7 parameter gradients are derivatives of the mean binary cross-entropy with respect to learned weights and biases. Chapter 8 stores an adjoint on every reachable graph node. A parameter node's adjoint is a parameter gradient when the selected graph output is the loss.
- `add_gradient(total: &mut f64, contribution: f64)` in the exercise and starter maps to `Value::add_gradient(&self, contribution: f64)` in the reference. The standalone `total` is the wrapped `self.0.borrow_mut().grad`; `RefCell` permits that mutation through `&self`. The old names were exercise `add_gradient`, starter `accumulate`, and reference `add_grad`.
- `Value::backward()` still clears every reachable adjoint, seeds the selected output with one, visits nodes in reverse topological order, and returns the existing nonfinite-value or overflow errors.

## Shapes and reductions

Chapter 08 operates on scalar `f64` graph values, so it introduces no tensor layout or dataset reduction. Contributions from every downstream path are summed into each node adjoint. Repeated `backward()` calls do not sum across calls because the implementation clears reachable adjoints first. The central-difference check keeps `h = 1e-5` and the course tolerance `1e-6 + 1e-4 * |numerical|`.
