| Before | After | Reason |
| --- | --- | --- |
| Reference `dense_matvec(weights, rows, cols, input)` and starter `dense(weights, rows, cols, x)` | Both use `dense_matvec_reference(weights, out_features, in_features, input)` | One scalar f32 oracle with one argument order and the course feature terminology. |

All changed Chapter 41 functions are private to their binaries. There is no public cross-crate API change. Chapter 36's public `parameter_spans()` names, ranges, order, `output_weight` span, and checkpoint bytes were not changed.

## Shapes, loss, and preserved behavior

- The scalar reference and quantized path both take row-major weights `[out_features,in_features]`, input features `[in_features]`, and return `[out_features]`.
- Chapter 36's output projection remains row-major `[D,V]`. Chapter 41 transposes it to `[V,D]` only to quantize one vocabulary-output row per scale, dequantizes that row view, transposes it back to `[D,V]`, and copies it into the unchanged `output_weight` span. A focused test proves the exact layout round trip.
- `quantization_error` returns RMSE averaged over every compared output coordinate plus maximum absolute error. `Decoder::loss` remains Chapter 36's mean next-token cross-entropy over T targets. No training update occurs.
- Symmetric scale calculation, qmax values (127 and 7), rounding, clamping, all-zero/subnormal handling, signed nibble encoding, low/high nibble order, odd-tail zero padding, fixtures, seeds, CLI, benchmark workload, printed output format, and thresholds are unchanged.
- The three Chapter 41 glossary slugs are defined only by this chapter; no duplicate glossary definition was found.
