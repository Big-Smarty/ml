# Chapter 20 consistency review

## Changes and interface mapping

- Chapter 11's `Dataset { images, labels, rows, cols }`, `width()`, and `image(n)` continue here. Labels now retain the Chapter 11 `u8` discrete-class representation; the generic loss argument is `target: usize`.
- `Model` became `Cnn`, `Forward` became `ForwardCache`, and `Grad` became `Gradient`. `forward(image) -> ForwardCache` computes logits and retains ReLU activations and max-pool winners for backpropagation. The task prediction remains the argmax class used by evaluation; the cache itself is not a prediction.
- `loss_and_grad(image, label)` became `loss_and_gradient(image, target)`. Opaque locals such as `dz`, `dpool`, `drelu`, and `g` became `logit_gradient`, `pooled_gradient`, `relu_gradient`, and `gradient`.
- The inline stable softmax and cross-entropy calculations became the Chapter 11 operations `probabilities(logits)` and `cross_entropy_from_logits(logits, target)`. The starter's `stable_softmax` received the same `probabilities` name.
- `rate` became `learning_rate`. Online SGD updates moved into `Optimizer::step(&mut self, model, gradient)`, and `step_count` increments once for each image update. `Cnn::train` still traverses the same images in the same order for the same number of epochs.
- The CNN's learned fields are explicitly named `convolution_weights`, `convolution_biases`, `dense_weights`, and `class_biases`; `Gradient` mirrors those names. This replaces Chapter 11's packed `Mlp.parameters` and `parameter_offsets` because the explicit convolution indexing is the chapter's learning objective. The dense head preserves [out_features,in_features] layout.
- The Rustlings `output_size` arguments became `input_size` and `kernel_size`. The lesson maps this one-dimensional shape primitive to the row and column dimensions of `Cnn::forward`. It also maps starter `convolution_at` to the inner padded cross-correlation used by the reference forward pass.

## Shapes and reductions

- `Dataset.images` is a flat row-major allocation with logical shape [examples,rows,cols]. `image(n)` returns one flat [rows*cols] slice, and image coordinates use `row * cols + col`.
- Convolution weights have logical shape [filters,3,3]. ReLU activations are [filters,rows,cols]. Two-by-two stride-two pooling produces [filters,floor(rows/2),floor(cols/2)].
- Dense weights have logical shape [classes,pooled_features] and flat index `class * pooled_features + feature`, matching the course [out_features,in_features] dense convention.
- `loss_and_gradient` returns stable cross-entropy and its complete parameter gradient for one image. It performs no minibatch averaging. Training has effective batch size one and takes one `Optimizer::step` per selected image per epoch.
- `metrics` sums loss and correct predictions over the selected images, then returns mean cross-entropy and the correct fraction. Its reduction is separate from the per-image training operation.
