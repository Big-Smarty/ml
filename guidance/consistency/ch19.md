# Chapter 19 consistency review

## Changes and interface mapping

- `Row { id, x, y }` became `Row { id, features, label }`. The stored `u8` is a binary class ID. Chapter 19 has no numeric regression target.
- `Scaler::fit(rows)` became `Scaler::fit(train_data)`, and `Scaler::apply(x)` became `Scaler::transform(&self, features)`, matching Chapter 14. A zero training-fold standard deviation still maps to scale one; this preserves valid fold fitting and is explicitly contrasted with Chapter 3's earlier standalone rejection policy.
- `Logistic` became the Chapter 4 name `LogisticModel`. `LogisticModel::fit(train_data, config)` adds fold-only scaler fitting and repeated updates to the earlier classifier. It stores `weights`, `bias`, and the fitted `scaler`; `Config { learning_rate, l2, epochs }` remains chosen input rather than learned state.
- `probability(&self, features)` and `predict(&self, features)` accept raw `[f64; 2]` features and apply the stored scaler before inference. `predict` returns the binary label obtained by thresholding probability at 0.5.
- `rate` became `learning_rate`; `w`, `b`, `dw`, and `db` became `weights`, `bias`, `weight_gradient`, and `bias_gradient`.
- `cv_accuracy` became `pooled_cv_accuracy`. The reference accumulates correct predictions and held-out row counts across folds, then divides once. The exercise and starter keep the smaller `pooled_accuracy(fold_counts)` arithmetic checkpoint and the lesson maps it to the end-to-end reference operation.
- Removed Chapter 19's duplicate `data-leakage` glossary definition. Chapter 5 remains the canonical owner; Chapter 19 links to that entry.

## Loss, shape, and sign conventions

- Each raw and transformed feature vector has shape `[2]`; the tabular collection is logically `[rows, 2]`.
- Logistic fitting follows mean binary cross-entropy over training-fold rows plus `0.5 * l2 * sum(weights²)`: it averages each data-gradient sum over the row count and adds `l2 * weight` to each weight update. The bias is not regularized. The algorithm and reduction are unchanged.
- The local classification error is `probability - label`, preserving the prediction-first sign. It is distinct from Chapter 15 boosting's correction residual `target - prediction = -error`.
- Accuracy is correct labels divided by evaluated rows. Pooled CV accuracy weights every held-out row equally; an unweighted average of fold accuracies differs when fold sizes differ.
