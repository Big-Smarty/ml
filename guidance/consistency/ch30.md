## Shapes, reductions, and synchronization

`matmul_scalar` and `Gpu::matmul` accept A `[m,k]` and B `[k,n]`, reduce the shared k dimension for each output, and return row-major C `[m,n]`. `matmul_scalar` visits `row`, `col`, then `inner`; the GPU kernel accumulates the same k products in 16-value tile rounds. The lesson states the absolute-plus-relative comparison and makes no bit-equality claim.

The matrix shader has workgroup dimensions `[16,16,1]`. Rust dispatches `[ceil(n/16),ceil(m/16),1]` workgroups, yielding a padded global grid `[16*ceil(n/16),16*ceil(m/16),1]`. Each workgroup owns one output tile and each local lane owns one output position.

The reduction shader has workgroup dimensions `[256,1,1]`; each lane may load two values, so a stage maps `[L]` to `[ceil(L/512)]`. `dispatch_params.element_count` is the current L. Workgroup barriers order only the lanes in one group. Ordered compute-pass boundaries separate stages and provide the cross-workgroup ordering that a workgroup barrier cannot.
