## Pedagogy and source discipline

Give a hand-worked input -> intermediate quantities -> answer before abstract generalization. Define every equation symbol and reduction convention. Trace implementation back to the maths. Show one failure with an explanation. Distinguish memorization from held-out improvement, simulation from hardware execution, and estimates from measured outputs. GPU chapters require real dispatch code and explicit missing-device errors. Distributed chapters include actual multiple local worker processes or threads with communication and distinguish this from multi-GPU verification. All advanced topics need runnable small experiments, not placeholders.

Use official docs, original papers, original project sources. Browse to verify current APIs.
