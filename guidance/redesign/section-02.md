## Dataset and honest limits

The offline fixture is ten **course-authored synthetic 5×3 block glyphs**, three brightness variants each for fit (30 rows), ten new-brightness held-out glyphs and two identical blank images with deliberately conflicting labels 1 and 7 (12 held-out rows). Fixture bytes traverse the real IDX parser. The conflict guarantees at least one error for a deterministic image-only predictor; it is an intentional ambiguity case, not an assertion about MNIST label quality. No default downloads, paid compute or network access.

The substantive MNIST material is retained: 60,000/10,000 official split, 28×28 bytes, big-endian magic/header/payload, normalization, format validation, explicit course preparation/download command, training-only validation split and untouched official test set. Both new digit classifiers accept four explicit uncompressed IDX paths plus bounded epochs. Missing/malformed inputs return errors. No MNIST performance was measured for this redesign, and earlier reference measurements are not presented as new lab results.

The MLP's default checkpoint is a temporary complete-state round trip and actual next-update comparison. The preserved original project still supplies persistent paths and zero-epoch evaluation. Exact continuation assumes the same next rows and order; there is no shuffle or schedule, and file saving does not sync the containing directory.

## Three focused tools

- **07 / `xor-hidden`**: linear sum boundary versus two hand-chosen sigmoid features. Native model select and threshold number input, deterministic reset, complete numerical table and original/hidden coordinate scatter. Reset hidden predictions `[0,1,1,0]`; moving the first threshold to 1.5 makes the two features identical and all predictions zero. Linear threshold .5 gets 3/4. This illustrates capacity, not trained parameters or Rust execution.
- **08 / `autodiff-tape`**: x*x+x; explicit reverse step button. At x=3, forward `[3,9,12]`; seeded adjoints `[0,0,1]`; after addition `[1,1,1]`; after multiply `[7,1,1]`. At x=-2 final adjoints `[-3,1,1]`. The live SVG displays forward values, current adjoints and both repeated operand paths; it has title/description and the numerical table is complete. No autoplay, color-only encoding or progress coupling.
- **09 / `tensor-digits`**, linked from 10 and 11: one stage at a time. Rectangular Y `[-1.5,3.5,-1.5,12.5]`; doubling inputs gives `[-3.5,7.5,-3.5,25.5]`. Digit stage explicitly uses hand-built prototype-distance weights and synthetic glyphs, with a numeric 5×3 pixel grid, ten scores/probabilities and fixed blank ambiguity. Optimizer stage holds the gradient sequence `[2×scale,0]`, rate .1 and beta values fixed: momentum parameters .8 then .62; Adam first parameter .9000000005 and second-step m=.18, v=.003996. These are illustrations, not measurements.

`node labs/s02-neural-networks/check_interactives.cjs` verifies pure calculations and changed states using Node's built-in assertions. Native labelled inputs/buttons/selects provide keyboard control and exact numeric alternatives; updates occur on change/click rather than a noisy continuous live region. Each tool has a static worked table/text fallback, scoped DOM selection and deterministic reset. Root owns the separate browser/rendering pass; this report does not claim it was completed by the section owner.
