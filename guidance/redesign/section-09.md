# Section 09 design and verification

Chapters 47–56 provide 25 sessions and 75 ordered question-led steps. Each session includes concrete arithmetic and tensor shapes, a whole-algorithm implementation or substantive audit checkpoint, graduated hints, explained results, and an unfamiliar input or failure case. The active route is `just lab NN`, `labs/s09-advanced/src/chNN.rs`, then `just lab-check NN`. Fully commented solutions are separate. Original reference projects are unchanged; meaningful heading anchors remain as aliases.

The design applies worked examples before generalized formulas, retrieval of the actual prerequisite, progressively independent algorithm work, and transfer that asks what changed and why. Counts, tolerances, and boundaries appear beside each numerical claim. A passing executable or illustration does not assess the learner’s explanatory answer.

## Focused illustration and accessibility

Chapter 48’s `routing-capacity` container is the only new browser tool in this section. Twelve ordered tokens have preferred logit 2 for their four-token group and 0 otherwise. Concentration adds a bias to expert zero. Separate labelled native range controls change concentration, capacity factor, or alpha; Reset restores the worked fixture. A table shows attempts, admissions, drops and mean probabilities. Text reports token decisions and a polite status output announces changes. No value is available only through color. A static worked example remains readable without JavaScript. No Rust execution, hidden training, network request or external asset is involved.

`node chapters/48/demo-check.cjs` exercises the actual calculation helper with Node assertions:

- Reset (bias 0, factor 1, alpha .02): attempts/admissions [4,4,4], capacity 4, no drops, probabilities 1/3, raw balance 1 and weighted balance .02.
- Factor .5: capacity 2, admissions[2,2,2], six drops, unchanged probabilities and raw balance.
- Bias 4: all 12 attempt expert0; capacity 4 admits 4 and drops 8; raw balance is 3×mean expert-zero probability.
- Bias 2: exact ties for other preferred groups resolve to the declared first expert.
- Alpha 0 removes auxiliary loss without changing routes; alpha .04 doubles the alpha .02 loss.

The arithmetic was tested directly. Browser layout and keyboard interaction remain part of the root’s integrated site review, rather than being claimed from arithmetic tests alone.

## Completion boundaries

No original topic was removed or renamed in `topic_coverage`. All sessions contain a changed-input answer as well as implementation evidence. A selected original literal reference excerpt and meaningful heading anchors remain available. Active lessons contain no retired exercise commands. No reference project was edited.

Storage, arithmetic, timing, objective improvement, sample quality, retrieval, drift, privacy evidence, causal identification and runtime parity remain distinct claims. The largest system is a tiny fully trained contextual model. Hardware acceleration, internet datasets, public serving, statistical certification and universal portability are not asserted. Default package execution needs no extra dependency.
